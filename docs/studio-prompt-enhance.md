# 提示词增强

Studio 首页「开始创作」板块的卡片「提示词增强」进 `#/enhance`（`studio/web/prompt-enhance/prompt-enhance.js`）。
顶栏没有这一枚页签：首页那张卡是这页唯一的来路，首页版式把这张卡删掉（在「添加卡片」里加回来），这一页也就进不去。
整页是一块聊天舞台——这一发的输入一条气泡（贴右），模型的回话一条气泡（贴左），底部一枚输入卡钉在页面下缘：
卡片外观就是绘画页输入卡那一副扁平描边（黑半透明底 + 浅描边），不给视频页那层浮动投影。
右上角那一枚「图像 / 视频」开关换的是整页作用域：技能清单只列那一类的增强技能，提示词的取用 / 骰子 / 存预设一起落那一池
（模式存 `localStorage["rs.enhance.media"]`，默认图像）。
舞台空着时中间一句起手引导（`.ns-enhance-guide`，字号配色就是绘画页与视频页共享的 `.neo-gallery-gm-idle`）：大字
「写一句，点增强」加一句细注。第一条气泡落下来就收，「新增会话」清空舞台后回到中间；点引导块本身回到输入框。
引导里不放第二套入口——抽词、取图、选技能都在下面那枚输入卡上。

## 这一发的形状

1. **写一句 / 贴一段**：主框是这页唯一的聊天输入——写画面描述、把已有提示词贴进来，Enter 发送、Shift+Enter 换行。
   骰子抽来的那条随机提示词拼在已有输入后面（`joinPromptText` 那条分隔线）。
2. **参考图**：编辑页那一副「＋参考」方块 + 取图浮层（`gallery.css` 的 `.neo-gallery-edit-refdrop` 族，两处共用一份样式），
   最多 4 张（`MAX_ENHANCE_REFS` = 后端 `studio/llm.py` 的 `MAX_REF_IMAGES`）。空格点击就是「🖼 素材库取用」（宿主的素材库弹窗），
   hover 方块行浮出浮层：头部「参考图 N/4」计数 +「⬆ 本地上传」（一次选多张）+「🖼 素材库取用」，离开方块留 250ms 关闭宽限
   （鼠标来得及跨过那 6px 间隙点中两项）。本地文件与素材卡直接拖进图位，粘贴进来同样吃；图位的 ✕ 摘掉那一张、后面的补位；
   视频与音频不进图位，满位报上限。输入卡底行没有「上传图片」那一枚——本地上传收在浮层里。素材库取用的落
   `{kind:"input", value:"<相对名>[output]"}`，本地上传与粘贴的落 `{kind:"data", data:<data URI>}`。
3. **技能**：清单只列当前那一池的分类——图像模式是 `image_enhance`，视频模式是 `video_enhance`；带 `workflow.json` 的技能与
   `gen_image` 技能不进这一页的清单，它们走出图链路。图像模式顶部一项是「智能判断」（空值，请求体不带 `skillId`，后端按输入
   长度自己挑：带图走图片反推、不带图走默认增强任务）。视频模式没有这一项——后端空 `skillId` 只认图像侧（`studio/llm.py`），
   清单默认落在第一条视频技能，chip 上写的就是它；一条视频增强技能都没有时点「增强」只说要去技能管理按「视频提示词增强」
   分类新建，不发这一发。
4. **思考深度**：`off` 发 `enable_thinking:false`，`low / medium / high` 发 `reasoning_effort`（`high` 是模板的 `xhigh` 档，
   映射在 `prompt-service.js` 的 `THINKING_EFFORTS`）。档位存 `localStorage["rs.thinking_depth"]`，与 NeoPromptAgent 节点同一把键。
5. **填词**：右上角那枚组合钮（`neo-split-btn`）左半从提示词库挑一条填进输入框，右半骰子抽一条随机提示词拼在已有输入后面。
   哪一池由模式定：`preset-picker.js` 的 `kind` 就是提示词管理页「图像 / 视频」那条池子规则（扫描名首段 `video/` 归视频），
   「保存为预设」也落同一池（视频那一发带 `video/` 前缀）。
6. **回话**：不套框——回话这条气泡没有壳，正文也不是带描边的框，元信息行、那一行状态位、正文与那两枚图标钮
   （「复制提示词」「保存为预设」，文字在悬停提示里）直接落在舞台上。正文多长写多高
   （`field-sizing: content`，上限 40vh 之后在区内滚，12px 字号）；思考与流程状态只占
   正文上方那一行细注（「思考中…」与阶段名，就是 `createStreamOutputHandlers` 传了 `lineEl` 那一发）——思考正文一个字
   也不上屏，正文一出现就收走，流结束也收走；`replace` 帧整段替换已透传的正文。NeoPromptAgent 节点面板与
   「查看技能执行过程」弹窗仍是 `.rs-thinking` 那块面板（不传 `lineEl` 就是旧行为）。
7. **会话**：每一发的输入与落定的回话攒在这一页的闭包里（`{role, text, refs}`），下一发默认垫在正文前面交给模型——
   后端那条增强链是单轮的（`studio/llm.py` 里的消息就是 `[system, user]`），历史就当正文送，请求体形状不变。
   只带最近 8 对（`HISTORY_PAIRS * 2` 条）、单条裁到 `HISTORY_CHAR_CAP`（4000）字；参考图在历史里只留一句「（附 N 张参考图）」，
   粘贴与上传的图字节只跟当前这一发。回话那条的元信息行写着这一发垫了几条（「带 N 条历史」）。空产出不留一条空回话。
   「新增会话」断在途的流、清空舞台与会话、收掉状态行，输入卡上的草稿留着；会话不落盘，切页回来还在。
8. **停止 / 复制 / 存预设**：运行中那枚「增强」就改写成了「停止」——按下去断流、作废在途那一发的迟到帧，
   已落的正文连着输入一起进会话，钮回到「增强」且不发灰；正文落定（完成、失败、停止都算）之后那条回话才浮出
   两枚图标钮——「复制提示词」「保存为预设」，页面上没有名字框：标题由后端从正文取（`/rs_prompts/extract_title`），
   那一发没给标题就用正文首行，存下去的就是那条回话的正文。空产出的回话不铺这一行。

一句描述与一张参考图都没有时不发请求，也不在舞台上留气泡。后端把失败写进流里（`[ERROR]` 帧）时，状态那一句报的就是
后端那句原因；选了技能就给「查看技能详情」那一发，没选技能给「打开 LLM 设置」。

## 离线形态

增强链全程只认数据根的技能文件（`GET /rs_prompts/skills`）、8080 与远程 LLM 的出流
（`POST /rs_prompts/stream_generate_prompt`）和 `input/` 里的参考图，桌面窗口不启动内核也跑得了
（`app/studio_caps.py` 的 `prompt_enhance` 一位在桌面端表内）。只有「保存为预设」是提示词库写侧：
`prompt_library_write` 不在桌面端表内，离线窗口把那颗钮写成「需要 ComfyUI」，点它交桌面端拉起内核；
页面自己也在取名之前就收住，不发一条注定 409 的写请求。
