# 图片反推

Studio 首页「编辑」板块的卡片「图片反推」进 `#/reverse`（`studio/web/reverse-prompt/reverse-prompt.js`）。
顶栏没有这一枚页签：首页那张卡是这页唯一的来路，首页版式把这张卡删掉（在「添加卡片」里加回来），这一页也就进不去。
反推用的是素材卡 ⋯ 菜单那一条接口（`POST /rs_prompts/reverse_prompt`，`studio/llm.py`），页面上只做
取图、上屏、复制三件事。

## 用这条路径

1. **挑一张图**：`从素材库选图` 开素材库弹窗，点一张卡片落上参考位；弹窗这一扇只放行图片
   （`accept: "image"`），视频与音频点它是开灯箱浏览。`换图` 开的是同一扇窗。
2. **选输出语言**：结果框标题那一行的 `中文` / `英文` 定的是下一发请求里的 `language`（后端认 `zh` / `en`），
   换语言不影响在途那一发。
3. **反推**：正文逐段落进结果框 —— 后端逐 token 经 SSE 推流，同时把成文写进图片同目录的 `.txt`，
   浏览素材库就看得见，与素材卡那条反推是同一份落点。
4. **复制提示词**：`复制提示词` 把结果框正文送进剪贴板；正文为空时只报「还没有可复制的提示词」，不写剪贴板。

换图与重跑会作废在途的那一条流：上一张图在途的正文不会落进新图的框里。后端把失败写进流里（`[ERROR]` 帧）时，
状态那一句报的就是后端那句原因，结果框不拿半截正文装成功。

## 离线形态

反推要吃内核那侧的 LLM 链与图片读取路径，桌面端窗口在 ComfyUI 未就绪时把「反推」写成「需要 ComfyUI」，
点它交桌面端拉起内核，不发一条注定 409 的请求（`app/studio_caps.py` 的 `prompt_reverse` 一位）。

## 智能体与 MCP

同一条接口开在 MCP 工具面上：`reverse_prompt`（`studio/mcp_server.py`）。右栏「智能体」与外部 MCP 客户端
用的就是这一条工具——图由 `filename` + `subfolder` 指认（`subfolder` 留空是 `presets`），语言走
`language=zh` / `en`，返回的是提示词正文，落点同样是图片同目录的同名 `.txt`。
