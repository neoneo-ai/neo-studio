# 提示词节点

覆盖 Neo Prompt Encoder / Neo Prompt Agent 两个提示词节点、共享界面与按钮、图片反推输入。
技能管理见 [skills.md](skills.md)。
LLM 模式与本地安装见 [llm.md](llm.md)。

## 📝 Neo Prompt Encoder - AI 驱动的提示词编码器

完整的提示词管理 + CLIP 编码节点：

- **提示词保存 / 选择** - 保存和加载预设提示词，支持 presets 和自定义目录。
- **LLM 提示词增强** - 使用远程 API 或本地 LLM 模型增强提示词质量，技能模板管理与快速切换。
- **快捷生成 / 随机生成** - 输入简短描述快速生成，或一键随机生成创意提示词。
- **图片转提示词** - 附加参考图（支持粘贴、拖拽、@ 引用工作流图片），AI 反推生成描述性提示词。
- **分类 / 标题提取** - 保存预设时 AI 自动分类内容并提取标题，一键保存提示词或配方。
- **技能系统** - 通过技能选择器调用不同能力，按组分类：图像提示词增强、视频提示词增强
  （generator / 全能参考）排最前，其后为图像 / 反推、直接生图或编辑、自定义；
  生视频（H3）与任务为内部使用技能，不在列表显示。

### 输入/输出

| 输入 | 类型 | 说明 |
|------|------|------|
| `clip` | CLIP | 文本编码器（必需） |
| `text_input` | STRING (forceInput) | 外部文本输入 |
| `image` | IMAGE | 参考图（用于图片转提示词） |

| 输出 | 类型 | 说明 |
|------|------|------|
| `POSITIVE` | CONDITIONING | 正向编码条件 |
| `PROMPT` | STRING | 最终提示词文本 |

## ⚡ Neo Prompt Agent - 简洁版提示词代理

轻量级提示词生成节点，专为仅使用生成的提示词文本、不需要 CLIP 编码的场景设计：

- **无需 CLIP 输入** - 不绑定文本编码器。
- **无状态栏 / 切换开关** - 界面更简洁。
- **输出 PROMPT + BUNDLE** - PROMPT 为提示词文本；BUNDLE 为本次生成的运行时包 id，
  供 🎨 Krea2 / 🎬 H3 按 id 消费（只携带 prompt 与参考图，不携带技能）。
- **技能下拉只列无 `workflow.json` 的技能** - 带工作流的技能由 `workflow.json` 驱动出图、正文不参与本节点，故不出现在这里。

![⚡ Neo Prompt Agent 节点](assets/images/neo-prompt-agent.png)

### 输入/输出

| 输入 | 类型 | 说明 |
|------|------|------|
| `prompt` | STRING (hidden) | 提示词文本（隐藏） |
| `instance_uid` | STRING (hidden) | 实例 ID（隐藏） |

| 输出 | 类型 | 说明 |
|------|------|------|
| `PROMPT` | STRING | 提示词字符串（多结果技能按条目循环消费） |
| `BUNDLE` | STRING | 运行时 bundle id（`bnd_*`），见下方说明 |

- `BUNDLE` 连到 🎨 Krea2 / 🎬 H3 的 `bundle` 输入，可一次性带上 prompt 与参考图
  （连线 / @ 引用 / 本地上传），不含技能。
- bundle 仅存内存，过期后下游安全回退本地输入。

## 📦 Neo Bundle Expand - BUNDLE 展开节点

把 ⚡ Neo Prompt Agent 的 **BUNDLE** 展开成标准输入槽，对齐官方 MiniMax H3 Reference to Video
的 `ref_images`（最多 9 张）：

- **输出槽自动增长** - 默认只显示 `prompt` + `image_1`；连上最后一个可见图片槽后露出下一个，上限 9 张。
- 执行后节点内只读展示提示词与参考图缩略图网格（按输出顺序）。视频 / 音频参考暂不展开。

| 输入 | 类型 | 说明 |
|------|------|------|
| `bundle` | STRING (forceInput) | ⚡ Neo Prompt Agent 的 BUNDLE 输出 |

| 输出 | 类型 | 说明 |
|------|------|------|
| `prompt` | STRING | bundle 内的提示词文本 |
| `image_1..image_9` | IMAGE | 参考图（最多 9 张，自动增长露出） |

## 🔲 Neo Reference Grid - 参考图宫格节点

单节点搞定「提示词 + 最多 12 张参考图」：

![图片处理节点](assets/images/image-process.png)

- **宫格槽位（1~12）** - 工具条 −/+ 运行时调整槽位数（默认 9，不随工作流保存；加载更多图时自动扩）。
  从左侧素材面板拖入 / 本地批量添加（可多选）/ OS 文件直接拖到宫格；瓷砖可拖放重排、✕ 移除、点击预览。
- **加载配方** - 工具条 ☰ 弹出选择窗，只列普通含图片的配方（排除多段导演与无图配方）；
  点击把图片（≤12）与提示词载入宫格。
- **宽度流式布局** - 列数按节点宽度排布（最小卡片宽 84px），卡片宽高跟随图片真实比例（整图可见不裁剪）；
  节点高度自动跟随内容。
- **输出槽自动增长** - 默认显示 `prompt` / `BUNDLE` / `image_1`，连线后逐槽露出到 `image_12`；
  执行后节点内显示本次实际用到的参考图数与来源顺序（格N）。
- **与配方联动** - 保存配方时宫格图作为**主图片资产**收集（排在连线 LoadImage 之前）；
  还原时优先填回宫格（≤12），其余再进 LoadImage，子图无 Neo Prompt 时提示词兜底写入宫格提示词框。

无可见输入（仅隐藏 `refs` / `prompt_text`）。

| 输出 | 类型 | 说明 |
|------|------|------|
| `prompt` | STRING | 节点内提示词框内容 |
| `BUNDLE` | STRING | 运行时包 id，可直连 🎨 Krea2 / 🎬 H3 或经 📦 Neo Bundle Expand 展开 |
| `image_1..image_12` | IMAGE | 按宫格槽位顺序的参考图；坏文件保留槽位空缺不补位 |

## 节点界面与按钮

两个节点共享同一套界面布局（Agent 不显示状态栏）：

| 控件 | 位置 | 功能 |
|------|------|------|
| LOCAL / EXTERNAL | 顶部状态栏 | 切换本地提示词 / 外部 text_input（连接后自动显示） |
| 🎲 | 文本区右下角 | 随机生成创意提示词 |
| ☰ | 文本区右下角 | 打开预设列表（支持搜索、删除、分类便签筛选） |
| 💾 | 文本区右下角 | 保存当前提示词或配方为预设，AI 自动提取标题与分类标签 |
| 👁 | 文本区右下角 | Markdown 预览开关（详见下） |
| ✕ | 文本区右上角 | 一键清空当前提示词，同步到控件与本地存储 |
| ＋ | 底部输入栏 | 附加参考图片（反推 / 多模态技能），支持粘贴、拖拽与 @ 引用 |
| 技能选择器 | 底部输入栏 | 选择本次生成使用的技能（详见 [skills.md](skills.md)） |
| 自动生成 ☐ | 底部输入栏 | 勾选后运行工作流时自动执行生成并实时回填结果 |
| ✨ | 底部输入栏 | 根据快捷输入描述生成提示词 |

- **Markdown 预览（👁）** - 生成结果识别为 Markdown（含标题 / 代码块 / 列表等）时自动切换为排版预览，
  点 👁 手动切换 / 切回原始编辑；流式生成时实时渲染；任务列表复选框（`- [ ]`）可直接点击勾选，
  选择会写回文本并带入下一次生成。清空提示词时预览一并清空。
- **分类便签** - 预设列表搜索框下方的图像 / 视频 / 配方三个便签：图像为除 `presets/video/` 外的提示词与集合，
  视频为 `presets/video/` 下的提示词，配方为普通配方。默认选中图像，选择记在前端本地存储，下次打开沿用。
- **技能选择器** - 选择本次生成使用的技能：图像 / 反推、任务、风格模板、自定义；
  悬停行时右侧显示浮动预览卡（生成技能 = 配置摘要，其余 = skill.md 正文摘录），点击卡片打开详情窗口；
  下拉底部 + New Skill / ⬆ ZIP / ⬆ Folder 为技能管理入口。
  首项是空值「默认」：不选技能时后端按 smart_prompt 自行判断要不要套模板，带图且未选技能时走反推。
  桌面端右栏的出图与出片一律交给后端智能体（`POST /neo_agent/run` 的 SSE 时间线，见 [api-routes.md](api-routes.md)）：
  输入框里打 `@` 直接点名技能——候选只收三条生成工具真跑得动的那批（`gen_image` / `gen_video` 且带
  `workflow.json`，与 `_gen_image_skills` / `_gen_video_skills` 同一判法），行右侧标出「生图 / 出片」，
  过滤与键盘口径与提示词页的 `/` 快捷菜单同一套工厂（`studio/web/slash-picker.js`）；选中的技能落在上下文条
  最左一颗 `🧩 技能名 ✕` 上（点 ✕ 取消；点名的技能只在当前这一条会话里有效——「＋ 新增会话」、
  断开续聊、读回另一条会话都收回它，不存本机，页面重载回到空态就是没有会话，那颗也就没有），
  随请求体 `skill_id` 进系统提示词，排在焦点链与用户偏好之后——本轮明说了用哪一发出图 / 出片就用哪一发，
  认不认得到这个技能由循环里那次 `list_skills` 定，认不到要说清原因再换，不许静默换。
  没点名时用哪个技能由 LLM 自己查 `list_skills` 定，工具表就是 MCP 全集
  （`director_run` / `segment_run` / `assemble_run` 出片链路在内）。对话里逐帧显示计划行、工具卡（参数 / 进度 /
  结果与产物缩略图：出图铺图、出片铺静音成片，点击进弹出窗口看大图与播放，不占用整扇窗口）与最终回答，进行中的
  任务卡带「取消任务」按钮。工具卡上的参数与结果是一行行的 JSON 原文，铺卡时展开成两档缩进，块定高 220px、
  长载荷在块内滚动（右下角抓手可拉长），解析不动的原文一个字都不改。时间线里的链接一律收在页面内：产物链接进弹出窗口，外部链接交新窗口，整扇窗口不会翻到
  图片 / 视频页——翻走再返回时 Studio 页重载，启动状态位与整条时间线一起没了。绘画页下方的中间舞台只跟当前这一轮：
  模式条与生成面板在上，采样动画在跑时铺在下方，产物一到预览就退场，那一块换给结果图，清单与最终回答收在下面。
  采样预览那一块按载荷的画面宽高比定宽（竖图 = 最长边 480px × 宽高比，横图铺满 720px 块宽上限）：定高配 100% 宽
  会把竖图裁成头部特写。中间舞台与采样预览各一个本机开关，在设置页「智能体偏好」栏
  （`localStorage["neo_studio_agent_stage"]` / `localStorage["neo_studio_agent_preview"]`，不进 `configs/agent_prefs.json`
  那六个会进系统提示词的字段）：关掉采样预览后这一轮请求的 `preview_side` 给 0，后端连预览表都不读、SSE 里不再有
  base64 帧，中间与右栏工具卡都不铺动画，中途关掉立刻收掉在跑的那段动画。
  输入框里 `↑` / `↓` 翻最近发出去的原文：本机存最近 30 条（`localStorage["neo_studio_agent_history"]`，换页重载还在），
  光标贴在最前按 `↑`、贴在最后按 `↓` 才起头，进了历史连按就一路翻，翻过最新一条回到自己写了一半的草稿，`Esc` 清空输入框时草稿一并丢掉。
  主按钮 **✨ 生成** 在底栏右下角，一个钮三态：空闲是生成，运行中变 **⏸ 暂停**（按首帧的 `run_id` 发
  `/neo_agent/pause`，循环停在下一个轮次 / 轮询边界，在飞的 ComfyUI 任务在边界上掐掉、不自动重发），
  暂停中变 **▶ 继续**（发 `/neo_agent/resume` 放开检查点）。整行 **⏹ 取消** 只在跑起来之后出现在文本框上面
  （Cline 的口径：没在跑就没有取消键，空闲时那一行不占位）：按下断流并按 `run_id` 发 `/neo_agent/cancel`，
  后端停循环、掐在飞的任务并放开 resume，挂在暂停检查点上的循环也退得出来，时间线落一行「⏹ 已取消」，
  取消请求本身失败就写在这一行里。页面导航或关闭导致的断流会取消后台循环并掐掉在跑的任务，
  不会在页面没了之后继续轮询。
  栏子默认收起，顶栏 **✨** 开合；栏子与页面视图之间一条分隔条，拖动调宽（栏子下限 260px、左侧页面视图下限
  420px），拖到比 150px 更窄整栏收起，双击收起 / 展开，键盘 `←`/`→` 微调，收起态按方向键展开落回收起前那一档
  宽度。开合与宽度存 `localStorage["neo_studio_agent_dock"]`，收起不抹掉宽度。
  栏子拖到 350px 以下时底栏一行只留字形（📎 / 🔌 / 📝 / ⚡ / ✨，点名技能那一颗只留 🧩，点它即取消点名）：整串标签留在 DOM 里做按钮的 `aria-label`
  （主按钮还带同名悬停说明），按钮整排可换行，右下角主按钮不会被栏子的 `overflow: hidden` 裁掉
  （`studio/web/agent-panel.css` 的 `@container (max-width: 334px)`，量的是 composer 内宽 = 栏宽 − 16px 内缩）。
  输入区里：顶上一条上下文条（📍 当前页 · 当前配方与段数 · 绘画模式 · 素材库目录），宿主在切页 /
  选配方 / 切绘画模式 / 开合素材库弹窗时刷新它，交来的只有当前选中页签自己那一栏：配方只在导演页报、
  模式只在绘画页报、素材库目录只在这三页上屏时报（`studio/agent.py` 的 `_context_block` 对同一份 payload 按同一页界收），
  目录带 👤 角色图标记时条上写「目录名（角色图）」、请求体的 `context` 带 `character_dir: true`（标记由画廊
  `isCharacterDir(视图)` 判，宿主交来的是自己那份视图），
  随请求体的 `context` 进系统提示词——智能体据此判断该围绕哪个配方、哪种模式干活。界面状态**默认不带**（干扰多于帮助，
  默认关掉）：条上写一行淡小字「不带界面上下文 · 点此启用」（这一态不画 📍，10px 小字走 `opacity: .45`），点条启用之后请求才带 `context`，条上的 **✕** 再关掉；这条开关存
  `localStorage["neo_studio_agent_ctx_on"]`，换页重载沿用，宿主刷新只换条上的显示；带上下文的轮次在回合头写明带的
  是什么，不带的轮次写「不带界面上下文」；
  📎 附件图（粘贴 / 拖入 / 点选，最多 6 张，缩略图可删）随请求体进多模态，只给图不给字也是合法一轮；
  粘贴 / 拖入 / 素材库拖入读成 data URI 是异步的，**✨ 生成**、Enter 与「🔁 重试」这一步先等在飞读图落地再取附件——
  界面上的缩略图与请求体里的图永远是同一份，发送始终是用户那一击，粘贴本身不发；回合头写明这一发「附件图 N 张」，
  零图那一发写「不带附件图」；执行模式跑完零附件又零产物的一发在时间线上铺一行「这一发没有附件图，也没有产物」的
  补素材提醒（计划模式、`[ERROR]` 收场、用户 **⏹ 取消** 与带了图的那一发都不铺）；
  执行模式里附件图默认就是本轮生成的参考图——`generate_image` 没写 `references` 时后端自动把它们接进去（粘贴的图落进
  `input/NeoAgent/`，按内容哈希去重、一条会话只落一次），出片时它们进本轮新建配方的角色参考与段参考（写已有配方一个字不改），
  素材库当前目录是角色图目录时这条新建配方照画廊 ⋯ 菜单同一条口径补成 `shared.mode=r2v` 全参考（三视图当首帧会让视频
  从设定图开镜；模型自己写了 `i2v` / `mixed` 就照他的，后端不顶他的值），
  模型显式传 `references: []` 就是纯文生图；带参考图的出图算的是编辑那张图，技能要收得了参考图——`list_skills` 的行里
  带 `mode` / `requires_ref`，`generate_image` 挑到 `mode=t2i` 的纯文生图技能时后端不发这一发，工具结果直接点名要换的
  `mode=edit / t2i_edit` 技能（画布导入的技能没有 `mode` 时看 `requires_ref`），与绘画页技能列表的过滤是同一条判法；
  反过来 `references` 为空时挑到 `mode=edit` 的纯编辑技能也发不出去（模板的参考图槽位是必填的，槽位空着后端就把模板
  当文生图跑完，出来的图跟用户的编辑意图无关），`list_skills` 的 `q` 连 `mode` 的值一起匹配，按纯文生图找技能 `q=t2i` 就够；
  主模型与 LoRA 的家族词（`krea2` / `qwen`，技能 id 与中文名里带的那个词）和技能不一致时同样在发出之前拒，
  `list_models` 回的 `suggested_*` 在提示词里写明是整套默认建议、不要照抄进这一发；
  同一发参数失败两次提示词要求停手，报错里的节点提示（`CLIPLoader` 的 type 这类）不是模型文件名，不许当 `q` 去搜；
  换主模型 / 加 LoRA 走单次覆盖：系统提示词交代 `list_models` 的 `q` / `group` / `near`（同目录那一排排最前、
  每项带 `dir`）与 `generate_image` 的 `model` / `loras`，只覆盖这一发请求，技能自定参数与全局生图设置不动，
  工具表里没有写技能配置的入口；描述里带人物 / 画风 / 作品名这类专名时提示词要求先按 `q` 搜一轮 LoRA——命中一项直接带上，
  命中多项弹「选项确认卡」让用户挑（末项固定「不用 LoRA」），没命中照常出图；点名主模型时同样按
  `list_models(group=diffusion_models, q=<关键词>)` 搜一轮（与 LoRA 共用那两个关键词的上限），技能要落在那一项的
  `skills` 里，`skills` 为空就问用户要哪个技能；`model` 对不上生图扫描的 `diffusion_models` 同样在发出之前拒，
  回候选文件名与「留空自动挑」的口径；
  **📝 计划 / ⚡ 执行** 开关定本轮跑不跑——计划模式里生成与写配方类工具不进 LLM 的工具表，硬调也拒回错误，收场要交出一份
  分步骤、写明工具与关键参数的计划；后端 `ask_user` 发一问就挂在循环上，时间线出「选项确认卡」（问题 + 2-5 个选项 +
  自由输入），点选经 `POST /neo_agent/answer` 交回去，答完锁卡，30 分钟无回应按「用户没回应」继续，按 `run_id` 取消时
  挂着的问句一并交收。执行模式里 @ 点名了技能、本轮没有附件图（焦点链里也没有产物图与成片）时，出片四类工具
  （`director_run` / `segment_run` / `assemble_run` / `director_keyframes`）第一次调用先弹一张写「本轮没有附件图」的
  素材确认卡（卡上带这一发的段数与量级）：点「⏹ 先不跑」这一发不入队、工具结果是 `[skipped]`，点「✅ 跑这一发」
  照文字跑；一次运行只弹这一次，用户偏好里的 `confirm_films` 量级卡与它是两张卡、各问各的。
  系统提示词逐轮带「本轮输入素材：附件图 N 张」——N 是这一发真进请求体的图数，N=0 时提示词要求缺素材的活
  先 `ask_user` 要素材，不许照文字凭空出片。
  一轮以 `[ERROR]` 收场（远程 LLM 502 这类一次性失败）时，文本框上方铺出一行「🔁 重试」：按上一发的原文、模式与附件图
  原样重发，界面当前状态按重发这一刻现读，重发是新的一轮、不带 `resume`；下一次 **✨ 生成**、「＋ 新增会话」与跑成的
  一轮都收掉这一行，用户主动 **⏹ 取消** 的那一发不铺它。输入框里还写着一发草稿时点它会提示先清空，不覆盖草稿。
  空态（没有对话时）默认铺最近 3 条会话（与 🗂 同一份摘要：一行一条，标题 + 日期），点一行即把那条会话的时间线铺回右栏并挂出「接上次会话」条，「查看全部 ›」打开完整列表；删掉会话后这一列表跟着收空。历史会话是数据根 `agent_sessions/` 里的文件，桌面端服务自己列 / 读 / 删，ComfyUI 没起来时最近列表照旧铺得出来（只有要内核的 `/neo_agent/run` 归 ComfyUI）。栏头 **＋** 新增会话（时间线收回带最近列表的空态、断开「接上次会话」条，下一条消息开一条新会话，后端保存的历史原样不动），**🗂** 打开会话列表（`GET /neo_agent/sessions`：一次运行一条、新的在前，列时间 / 模式 / 终态 / 标题 / 工具数），整页列表自带栏头 **✕**，点一下收回时间线；
  会话标题就是整条对话的第一句话，落盘时定下来：右栏栏头那一行在整场生成里钉着这一句（栏头宽度不够时截断，
  整句在悬停说明里），中间舞台页眉挂同一句，列表行与读回的旧会话认的都是这一句，续聊那一发不换它；
  只给附件图、没有文字的那一发落在「（只给了附件图）」这一句占位上。
  点「打开」把那条会话的时间线**只读**铺回右栏——自己那一发的原文与附件图缩略图也在时间线里
  （落盘的 `in` 帧；早于这个帧的老会话由界面从 `input` 补回那一句）；跑完的循环没有可取消的任务，问句卡整排置灰；铺开后文本框上方出现
  「↩ 接上次会话」条，下一句 **✨ 生成** 带着那条会话的 `run_id` 发 `resume`，落下来的旧对话原文接在系统提示词之后
  由 LLM 接着跑（换到计划模式续聊同一条路，旧的 system 不落盘、按这一次重生成）。一次运行一个 JSON 落在数据根的
  `agent_sessions/`，文件带本轮产物数 `media` 与收场原因 `reason`（`finish` / `answer` / `turns_exhausted` /
  `cancelled`，循环没走到收场分支时落那一次的终态名），`GET /neo_agent/sessions` 的摘要带同一对字段——零产物 +
  `turns_exhausted` 那种会话在列表里就看得出来；垃圾桶图标钮连着删后端保存的历史（一次点击一次确认）；整页列表的行删除与回放栏头的删除同为垃圾桶图标，删一条会话也是先确认再删文件。
  右栏也能走这条链：`director_plan`（拆分，写 `story`）→ `director_save` → `director_keyframes`（关键帧落进配方
  `assets/`）→ 把返回的 `segments` / `shared` / `story` 原样喂回 `director_save`（记 `storyboard` 与非全参考段的
  首帧）→ `segment_run` / `director_run`；与 📖 页同一套后端，见 [mcp.md](mcp.md)。
  执行模式里 `director_save` / `director_copy` 一保存成功，右栏就广播导演编辑器那条同一份的保存事件：导演页配方弹窗的
  配方列表当场刷到这份新配方并选中它，点开即进编辑器改分段与参数，整片与单段从同一份配方复用；计划模式这两个工具
  不进工具表。
  最终回答末尾的「下一步选项」编号列表铺成一排整行可点的方向（标题只认一行的短标题：「下一步 / 接下来 / 后续」
  配「选项 / 方向 / 建议 / 操作」，或英文 Options / Choices / Next options）——点一下就把这句话填进输入框并作为
  下一轮请求发出，与用户自己敲这句话是同一条路径；选过的那组锁住并留下「✔ 所选项」，跑起来时上一轮留下的方向
  按钮整排锁住、本轮收场放开；整行铺满栏宽、文字折行，右栏拖到 260px 下限也不截断。编号项少于 2 条或多于 6 条，
  以及没有这种标题的编号列表（计划模式交出的分步计划），照原文渲染成文本，不铺成按钮。
  增强类技能仍只出提示词，走 `/rs_prompts/stream_generate_prompt`。
- **多轮交互技能** - 选中声明了 `multi_turn` 的技能时，节点最底部按需显示一行小字提示
  （切换或取消该技能后自动隐藏）：每次生成仅推进一个阶段，需把返回的问询补充完整后再次点击 ✨ 继续下一阶段。
- **快捷输入历史** - 底部快捷输入栏支持命令终端式 ↑/↓ 召回之前用过的输入
  （本地持久化、去重、最新在前、上限 20 条）；编辑内容即退出导航态，两类节点共用同一份历史。

## 技能管理

技能构成、技能管理窗口、工作流区内嵌编辑、技能 ⇄ 画布导入与回写、回写确认与变更记录见 [skills.md](skills.md)。

节点底部的技能选择器按用途分组展示可选技能：🖼️ 图像 / 反推、🎨 风格模板、📝 自定义

## 图片反推与图片输入

选用 📷 图像 / 反推类技能时，可通过以下方式提供参考图片：

| 方式 | 操作 | 说明 |
|------|------|------|
| ＋ 按钮 | 点击输入框旁的 ＋ | 打开文件选择器选取本地图片 |
| 剪贴板粘贴 | `Ctrl+V` | 自动转 base64 并生成缩略 chip |
| 拖拽导入 | 将本地图片拖入快捷输入框 | 自动读取并生成缩略 chip |
| `@` 引用 | 在输入框中键入 `@` | 列出当前工作流所有可用 Load Image 节点图片 |

素材联动：素材中「复制到 Input」会把图片放入 ComfyUI 的 input 目录，之后可在工作流 Load Image 节点中选用，
并通过 `@` 选择器引用到反推输入；素材灯箱的发送按钮也可直接把图片附带的信息回填到 Neo Prompt 节点。

### `@` 图片引用

在快捷输入框的任意位置键入 `@` 唤起图片选择器，弹层自动定位到光标附近：

- **图片来源** - 自动扫描当前工作流中所有 Load Image 类节点（含变体），跳过 BYPASS / 已禁用的节点。
- **条目徽章** -
  `#N`：该图片已连线到本节点的 IMAGE 输入槽，`N` 为参数位编号，插入后在 `@` 处生成 `<Picture N>` 标记；
  `✓`：无连线但已附加为反推附件；无徽章：未连线图片，点击仅作为反推附件附加，不占用 `<Picture N>` 编号。
- **键盘操作** - `↑`/`↓` 移动高亮，`Home`/`End` 跳转首尾，`Enter` 插入选中项，`Esc` 关闭；
  删除 `@` 字符时弹层自动关闭。
- **判重与编号** - 同一图片不会被重复附加；编号由工作流 Load Image 节点的参数顺序决定，
  与缩略 chip 上的编号徽章保持一致。

**缩略 chip 与图片标记**

- 附加的图片以缩略 chip 形式显示在快捷输入框上方，悬停可放大预览原图，点 ✕ 移除。
- 带 `N` 编号徽章的 chip 对应正文中的 `<Picture N>` 标记，用于描述多张图片之间的交互。
- 无编号 chip 仅作为反推附件随请求发送。

### `/` 技能快捷菜单

在快捷输入框键入 `/` 唤起技能快捷菜单，弹层定位到输入框下方，随后续输入实时过滤
（按技能名称 / id / 标签，忽略大小写；中文技能支持拼音全拼与首字母缩写匹配）：

![`/` 技能快捷菜单](assets/images/prompts-slash-menu.png)

- **过滤** - 每敲一个字符即重新过滤；空 query 列出全部技能并按分类排序；query 含空白或删掉 `/` 时自动关闭。
  中文技能可输拼音（如 `dmfg` / `dongman` 命中「动漫风格」）。
- **列表项** - 每行显示技能名（需图带 📷 徽标）与所属类别名称，不显示内部 id。
- **键盘操作** - `↑`/`↓` 移动高亮，`Home`/`End` 跳转首尾，`Enter` 或 `Tab` 提交当前高亮项，`Esc` 关闭；
  只过滤不自动提交，始终需要按一次键确认。
- **提交效果** - 将选中技能写入节点底部的技能下拉（与手动选择等价），并清除输入框中的 `/xxx` 前缀，
  焦点留在输入框继续输入。

适合纯键盘快速切换技能：打 `/` + 名称片段，方向键定位后回车即可。

后端实现见 [architecture.md](architecture.md)（`prompt_agent.py` / `prompt_encoder.py`），
API 见 [api-routes.md](api-routes.md)。
