# 视频反推

Studio 首页「编辑」板块的卡片「视频反推」进 `#/reverse_video`（`studio/web/reverse-video/reverse-video.js`）。
顶栏没有这一枚页签：首页那张卡是这页唯一的来路，首页版式把这张卡删掉（在「添加卡片」里加回来），这一页也就进不去。
接口是 `POST /rs_prompts/reverse_video_prompt`（`studio/llm.py`）——与「图片反推」页是两条接口、两个落点，
页与页互不牵扯。

## 用这条路径

1. **挑一条视频**：`从素材库选视频` 开素材库弹窗，点一条卡片进播放器（弹窗这一扇只放行视频，`accept: "video"`）；
   播放器读的是 `/neo_frames/video` 那一条分段响应，seek 才有帧定位。`换视频` 开的是同一扇窗。
2. **拖时间窗**：播放器下面一条时间窗，默认铺满全片。按住两头的柄拖就是选闭区间，拖到哪儿播放器跳到那一帧预览；
   两个柄不交叉，端点出不了片尾，`全片` 一键铺回全片。键盘走查能 Tab 到滑轨：`←` `→` 把离窗口中心近的那侧柄挪
   0.5 秒（`Shift` 挪 5 秒），`Home` 铺回全片。`帧数` 定这一批抽几帧（1 / 2 / 4 / 6 / 8 / 12），
   窗上的刻度标的就是这一批落在哪几秒。整页一条居中竖列，播放器站在页面正中。
3. **抽帧**：在浏览器里做——复用「视频抽帧」页那套 canvas 取帧（`studio/web/frames/frames.js` 的 `rangeTimes`
   与 `captureFrames`），时间窗均分 N 帧、缩到 768px 边长。帧条上每一张都带自己那一秒的标签；这批帧只在这里看一眼，
   不存进素材库。
4. **选输出语言**：结果框标题那一行的 `中文` / `英文` 定的是下一发请求里的 `language`（后端认 `zh` / `en`），
   换语言不影响在途那一发。
5. **反推**：整批帧带各自的时间戳一次进请求，正文逐段落进结果区——结果区在正文开始回来的那一刻才出现，
   反推之前页面上没有这一块；正文不套框，直接铺在页面上，成文写进视频同目录的 `<视频>.rp.txt`，浏览素材库就看得见。
   整页只有一根滚动条（外层页面那一根）：播放器、帧条、正文全在同一条竖列里往下排，正文每落一块页面自动跟到底，
   正文自己不带滚动条。「反推中 / 已生成 / 失败」那一句写在结果框外面，框收着的时候也看得见。
6. **复制提示词**：`复制提示词` 把结果框正文送进剪贴板；正文为空时只报「还没有可复制的提示词」，不写剪贴板。

时间戳标签就是正文里的那一行（中文 `帧1@00:06.900`、英文 `frame 1 at 00:06.900`）：模型据此读运镜、节奏与先后，
没有时间标签的多张图在模型眼里互不相关。时间窗之外的画面不落字，正文只写这一段里看得见的东西。

落点是 `.rp.txt` 而不是同名 `.txt`：视频同名 `.txt` 是「视频再来一发」读进去的生效参数旁车
（`studio/gallery.py` 的 `_read_sidecar`），反推结果落进去等于一发把用户的生成参数覆盖掉。
换语言或换帧数会重跑——后端把这一对一起写进 `<视频>.rp-lang` 标记，命中缓存的条件是语言与帧数都与请求一致。

换视频会作废在途的那一条流：上一条视频在途的正文不会落进这一条的框里，帧条与结果框一起清空。
后端把失败写进流里（`[ERROR]` 帧）时，状态那一句报的就是后端那句原因，结果框不拿半截正文装成功。
一次超过 12 帧的请求由后端当场拒掉（`REVERSE_VIDEO_MAX_FRAMES`），界面上的帧数候选就到这一档。

页面起手只有那张卡片：语言 chip 与复制钮都在结果区里，出结果之前页面上没有这一块；选上视频后播放器、
时间窗与帧条直接站在页面上，出结果也不套框，整页一条居中竖列。

## 离线形态

反推链注册在 `studio/llm.py` 的 routes 上，桌面端离线窗口自己就服务这一发（`app/studio_caps.py` 的
`prompt_reverse_video` 一位）：取视频用 gallery 的媒体查找器、成文写 `<视频>.rp.txt`，全程 LLM 链与文件系统，
不碰执行队列。抽帧本身也在浏览器里做，整页在离线窗口里跑得出，不需要 ComfyUI 起来。
要配的只有 LLM；原生引擎一次只吃第一帧，多帧那一发由后端当场拒掉（见 [llm.md](llm.md)）。

## 智能体与 MCP

MCP 只开图片那一条（`reverse_prompt`，`studio/mcp_server.py`）。视频反推要的是浏览器播放器里抽出来的帧序列，
MCP 侧没有播放器，就不开一条只能收空帧的工具。
