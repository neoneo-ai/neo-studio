# 画布

图片与提示词，铺在一张画布上。画布页把图片节点、提示词节点、图像生成节点、图像编辑节点、文本增强节点、图片反推节点、视频节点与车厢（配方节点）摆在同一张能缩放平移的画面里，节点之间的连线决定出图与出片带哪些提示词与参考图，也决定出完的图与成片落在哪儿。页面在 `studio/web/studio/pages/canvas/`（`page.js` 是这一页，`geometry.js` / `nodes.js` / `interactions.js` / `store.js` / `history.js` / `node-types.js` 在它下面，生成层按族分文件：`gen.js` 装配与分发、`gen-state.js` 运行态、`gen-catalog.js` 只读清单、`gen-controls.js` 卡面控件基座、`gen-image.js` 出图与编辑、`gen-video.js` 出片、`gen-recipe.js` 串联与配方、`gen-llm.js` 增强 / 反推 / 故事板），一份画布的节点与连线落数据根 `canvas/<画布 id>.json`。

## 这一页在哪

- Studio 装配层的 `canvas` 视图：桌面窗口与插件页面同一条路（`studio/web/studio/studio-app.js` 里的 `createCanvasPage`）。素材库与画廊里的「摆到画布」把选中的素材送进这一页，按不重叠的网格铺成图片节点，每张按图自己的比例落那一格。
- 桌面窗口没有 ComfyUI 运行时也进得来：`/neo_canvas/*` 五条全在 `app/studio_caps.py` 的画布组里，画布读写是纯文件层。出图与出片那一发要执行队列，没有队列时按这一发只说一句「出图需要 ComfyUI 执行队列：点顶栏 ComfyUI 胶囊启动，好了再按一次」，不替用户去拉内核——拉一次就是收回在跑的内核正在用的代理目标，与绘画页出图同一口径，按钮也不锁死。

## 工具条

工具条只一行、不换行：全部是图标钮，名字写在悬停提示与 `aria-label` 里，有快捷键的那几枚把组合键写在悬停提示里；窗口不够宽时整条在条内横向滚（不显示滚动条），不掉到第二行。三组之间一条竖线。

- **画布组**：条上只一枚画布名钮（当前画布名 + 箭头），这一组不摆图标钮。点开是一列画布，面板钉在钮下方：点某一行名字就切到那张画布，重命名 与 删除画布 两枚图标钮收在每一行右端——指针落到那一行、键盘 Tab 进那一行才现出来（触屏档没有 hover，两枚常显），改与删都只动那一行的画布；末行是 新建画布。一张画布都没有时列表里就没有改名与删除可按。删除画布弹确认，连这一份 `canvas/<画布 id>.json` 一起收掉。
- **节点组**：一枚「加节点」下拉菜单（点开按 文字 / 图像 / 视频 三大类铺开，一类一小行标题，标题下是 加提示词 / 加文本增强节点 / 加文字故事板节点、加图片 / 加图像生成节点 / 加图像编辑节点 / 加图片反推节点、加视频生成节点 / 加视频输入 / 加音频输入 / 添加配方 十一行；标题行只是归类，不可按。菜单钉在钮下方），随后是 撤销（Ctrl+Z）与 重做（Ctrl+Shift+Z 或 Ctrl+Y）。剪贴板那四发不上条，走键盘：复制选中 Ctrl+D、剪切选中 Ctrl+X、复制 Ctrl+C、粘贴 Ctrl+V，选中节点与选中连线都认。菜单里每一行是图标加名字（名字同时写在悬停提示与 `aria-label` 里）；点完一项菜单自己收起，按条上那枚钮、按条外任何一处或 Esc 也都收起。没有可撤销 / 可重做时那两枚是灰的，灰着时悬停不亮。加图片 / 加视频输入 / 加音频输入 开的是素材库弹窗，开窗直接落在 图片 / 视频 / 音频 那一类标签上（这一扇只收这一类，标签见素材库的归类快捷筛选）。
- **视图组**：缩小 / 当前比例 / 放大，一条竖线后是 适应内容 与 背景（圆点 / 细线 / 空白三挡），最右是保存状态那一格（未保存 / {秒} 秒后保存 / 已保存 / 保存失败 / 离线）。

## 节点

| 节点         | 这一张是什么                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 提示词节点   | 一整块正文，文字存在 `metadata.content`；一条线指向图像生成节点时，它的文字按连线顺序拼进这一发的提示词。进编辑是双击正文，Esc 出编辑，落在节点外那一按也出编辑。                                                                                                                                                                                                                                                                                                                                                                                     |                                                                           
| 图片节点     | 一张图，坐标就是素材库的 `filename` + `subfolder`，画面上走 Gallery 缩略图，取不到落占位图。素材卡片与本地文件拖进画布按文件类型落成图片 / 视频输入 / 音频输入节点，落在某一张节点上就是换那一张（见「拖进来的输入」）。图片节点按这张图自己的比例落那一格：横图压矮、竖图收窄，长边不超出这一类节点默认那一档（340×360，竖友好那一档）；换上去的那一张读出来就按它自己的比例重落这一格，拉过的尺寸与串联素材那种小卡不重铺。                                                                                                                                                                                                    |
| 图像生成节点 | 一张铺满控件的卡（见下节）。它自己不带提示词：提示词与参考图都从连进来的那条线那头取。                                                                                                                                                                                                                                                                                                                                                                                                                                                            |                                                                               
| 视频生成节点 | 图像生成节点那一张卡把种类换成视频（`metadata.kind = "video"`，见下节）：技能、时长、尺寸三枚胶囊，出片走简单视频链。                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                           
| 图像编辑节点 | 图像编辑链的那一张（`type = "edit"`，见「图像编辑节点」）：卡上就是技能胶囊、张数胶囊与出图，它自己不带图也不带正文 —— 被改的那一张与要用的提示词都从连进来的线那头取。                                                                                                                                                                                                                                                                                                                                                                           |                                                                             
| 文本增强节点 | 提示词增强那条链在画布上的那一张卡（`type = "enhance"`，见「文本增强节点与图片反推节点」）：卡上一枚技能胶囊（留空 = 后端按输入智能判断）与一枚「增强」钮，最后一行是这一发的字数进度。它自己不带正文 —— 要重写的字从连进来的提示词节点按连线顺序取，成文写进下游的提示词节点。                                                                                                                                                                                                                                                                           |                                                                     
| 图片反推节点 | 图片反推那条链在画布上的那一张卡（`type = "reverse"`，见「文本增强节点与图片反推节点」）：卡上一枚语言胶囊（中文 / 英文）与一枚「反推」钮，最后一行是这一发的字数进度。它自己不带图 —— 连线顺序里第一张带素材路径的图片节点就是被反推的那一张，成文写进下游的提示词节点                                                                                                                                                                                                                                                                                  。 |                                                                   
| 文字故事板节点 | 文字故事板那条链在画布上的那一张卡（`type = "storyboard"`，见「文字故事板节点」）：卡上是正文框（一个主题或整篇剧本，点一下就能写）、每一段时长那一枚数框（点一下就能改）与一枚「生成段提示词」钮，最后一行是这一发的状态。它自己带正文 —— 与车厢自己写那一句同一份存法；成文按连线顺序写进连过来的车厢。在途的那一发送的是起手这一段话，正文框与每段时长那一格跟着锁，跑完回到能写。                                                                                                                                                                                                                                                                   |                                                                 
| 车厢         | 导演页那一份配方铺到画布上的那一段（`type = "recipe"`，见「添加配方」）：段号、这一段时长那一枚数框、这一段用的技能、正文与参考素材的出处和预览，卡上一枚钮都没有；整列共用的那一个视频技能与锚点 / 连续性 / 上下文帧 / 步数 / 种子在它那一列的车尾上。                                                                                                                                                                                                                                                                                                           |                                                               
| 视频节点     | 一段成片的落点：`metadata.filename` + `subfolder` 有值就播 `/neo_gallery/video`（出片落的那一张静音），空着挂「空视频位」占位。                                                                                                                                                                                                                                                                                                                                                                                                                   |                                                                               
| 视频输入节点 | 从素材库取的一段参考片（`metadata.filename` + `subfolder`）：整张播那一段片，带音轨不静音 —— 连进图像生成节点就是那一路的参考视频，按连线顺序进 `references.videos`。那一段的宽高读出来就按它的比例落框，换一段就重落。空着挂「空视频输入」占位。                                                                                                                                                                                                                                                                                                     |                                                                         
| 音频输入节点 | 从素材库取的一段参考声音（`metadata.filename` + `subfolder`）：卡上是浏览器自绘的那一条播控加下面一行文件名 —— 连进图像生成节点就是那一路的参考音频，按连线顺序进 `references.audios`。空着挂「空音频输入」占位。                                                                                                                                                                                                                                                                                                                                     |                                                                         
| 主图         | 被记为 `metadata.hero` 的图片节点左上角挂着「主图」徽标；节点选中时从节点上方那一排里换。                                                                                                                                                                                                                                                                                                                                                                                                                                                         |                                                                               
| 停用         | 整张压暗并挂「已停用」徽标（`metadata.disabled`）：出图、出片与整列出片都跳过它，连过来的正文与参考图也不进那一发，停用的那一张不当成片落点。                                                                                                                                                                                                                                                                                                                                                                                                     |
| 附加操作栏   | 节点选中时浮在节点上沿外头那一排（栏在节点外，不盖卡上的控件与正文）：头一枚是「停用 / 启用」，图片节点多一枚「选图」/「换图」（开素材库只收图片；换成串联素材那一张时配方那一份出处一起收掉），视频输入与音频输入节点多一枚「取用素材」/「换素材」（各开各的素材库，只收片与声音），图片节点有「设为主图」，提示词节点多一枚「提示词」（开绘画页同一扇提示词浮层，点一行把整段全文填进正文框），每类节点都有「复制节点」与「删除节点」。删除把节点和连着它的那些线一起收掉。栏上的图标分得开：停用是圆圈上一道斜杠、启用是一枚勾、删除是垃圾桶。 |

接线在节点四面上：左与上是入，右与下是出，从出接线点起手拖到另一张节点上算一条线，落在空白里说一句「连线要落在一个节点上」。四枚接线点平时收着不占视线，节点悬停、被选中、正被拉线瞄着时才亮出来（触屏档一直亮着）。两张节点上下叠放时线走竖的那一条：出底边、落顶边 —— 串联展开铺在车厢正上方那块正文与铺在正下方的素材都就近接到车厢那两面，不再绕到右中。四个角上的尺寸柄改这一张的宽高，方向键把选中的节点挪 8px（按住 Shift 挪 40px），每一步都能撤销。

## 拖进来的输入（本地文件与素材卡片）

从资源管理器 / 访达把文件拖到画布上，按扩展名落输入节点：图片落图片节点，视频落视频输入节点，音频落音频输入节点，`.txt` / `.md` / `.csv` 落提示词节点（正文读进 `metadata.content`，不发上传）。落在画布空白就是添加 —— 多张图按落点铺成不重叠网格，片、声音与正文一份一张；落在某一张节点上就是换那一张，多出来的按添加铺开。类型对不上的那张节点不动，按类型另建一张输入节点并说一句「这一张节点吃的是图片 · 已另建一张视频输入」。换上去的图片与视频输入节点先把框收回默认那一档，再按新素材自己的比例重落。指针停在哪一枚节点上，那一枚就亮起虚线描边 —— 这一放是换它。素材库卡片走同一条规则：落空白是添加，落节点是更换。

- 图片 / 视频 / 音频走画布自己那条文件写入（`POST /neo_canvas/upload`）落进 `input/`，同名追加序号，画布拿到的是落盘后的那一份名字 —— 画布的预览与出片只认这个目录里的文件。**拖放是文件操作，ComfyUI 在不在跑都落得下**：这条路由登记在桌面端离线服务那一张表里（`app/studio_caps.py` 的 `_CANVAS`），预览走的也是 `/neo_gallery/image` 这一族离线读得到的路由。体积超出去的那一张说的是「上传失败（413）：{文件名}」，只说它自己，旁边那一张照样落；正文文件在这台机器上读，不吃内核。
- 正文超过 20000 字只留前 20000 字并说一句；画布不收的扩展名（`.zip` 这类）只说一句「画布不吃这个文件」，不落一张永远读不出来的节点。
- 整发可撤销：一次拖进来的那一批图算一次撤销，换上去的那一张走「换图」那一条撤销。

## 图像生成节点上那一张卡

| 控件       | 说明                                                                                                                                                                                                                                                                                                 |
|-----------| -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 技能胶囊   | 图标加技能名的一枚胶囊，宽度按内容自适应；点开就是绘画页那一枚技能弹窗——左栏从技能页那一份生图技能清单里换一枚（新铺的默认落上一次用的那一枚），右栏改这一发的主模型与 LoRA。卡片上的主模型那一行按这一枚技能的 config 读，读到写模型名，读不到写「主模型：跟随技能配置」。                          |
| 参数那一行 | 比例、长边、张数挤在同一行，各一枚胶囊，控件含义写在悬停提示里。比例与长边默认跟随技能 config 与全局生图设置，胶囊上写「默认比例」「长边尺寸」，盖过的写生效值；比例胶囊的图标就是那个比例的形状。张数点开从 1 到 8 里选一枚（后端一次最多吃 8 张）。                                                |
| 出图       | 独占最后一行的主按钮：主色实底铺满。这一发在跑时收成软底，位置与宽度都不动。                                                                                                                                                                                                                         |
| 自定参数   | 就在技能弹窗右栏：这一发临时换的主模型与 LoRA（表单与绘画页那块共享同一份），留空 = 跟随该技能 config 与全局生图设置。改动当场写进 `metadata.gen_params`（可撤销、随画布落盘），换技能整项清掉；手填的主模型与该技能家族对撞时当场收回这一选并说清楚；模型清单没读到（离线）时右栏那几行铺不出东西。 |
| 取消任务   | 这一发在排队或在跑时才出现；按下去交后端出队，节点收回不挂运行态。                                                                                                                                                                                                                                   |
| 状态那一行 | 「排队中」「生成中 {done}/{total}」跟着后端那一发的进度走；失败时这一行写失败原因，卡片收红。                                                                                                                                                                                                        |

- 控件的改动当场写进节点的 `metadata`：可撤销、随复制走、随画布落盘。卡上的胶囊、按钮与种子输入，连同浮出栏那几枚，起手不吃这一按（交浏览器在它们上面发 click），按下去就是选中这一张（生成卡与串联车厢整张铺的都是控件，按完不选就看不出按的是哪一张）。卡上其余地方按下拖拖的就是这一张节点——概览行、配方提示词行、参考素材计数、状态与主模型那几行都在其内，正文也不给浏览器选走（`.ns-canvas-node` 整张禁选，只有正文编辑框与种子输入照常可选）。正文框与视频那一格是浏览器先拿：拖过 8px 那一截才挪节点，没拖过就是选字与翻播放。视频那一张整张铺的是播控（进度条 / 音量 / 全屏交浏览器，底部那一条拖的是进度条，节点不跟着走），卡上没有按得中的空白，固定抓手在浮出栏首那一枚（`span`，起手不吃那一截，按下就拖，选中多张时拖走整组）。
- 胶囊的菜单与技能弹窗那块面板都浮在页面那一层（`.ns-canvas-gen-menus`），不在节点里：世界层带 scale，进那一层才不跟着缩放、也不会被控件行与节点裁剪切掉。节点每重画一次这一层清空一次，面板开着时重画完在原处接着弹开；这一发在跑时面板挂 `ns-canvas-params-busy`，两栏一起收控件（跑着的一发不改参数），收摊与整列取消当场恢复。
- 出图请求按连线顺序带上游的提示词与参考图。没有可用的线时说一句「接一条文本或图片线过来再出图」；那一枚技能不吃文本提示词时点名它要参考图。
- 自定参数存在节点的 `metadata.gen_params`（`model` / `loras`）：出图请求只带这一发盖过的项，空值不进请求，后端按技能 config 与全局生图设置合并；卡上「主模型」那一行写的就是这一发真正生效的那一套。
- 出完的图按连线顺序填下游空着的图片节点，多出来的在右侧新建图片节点并接在这张图像生成节点上；撤销一次退掉这一发落下的全部图。
- 切走画布或删掉来源节点时这一发脱手：结果不写旧画布，只说一句「图已存进 Output 目录」。
- 技能缺 API Key 时报一句并开技能管理去填；提交失败报「出图失败」，成功报「已出图 {n} 张」。

- 一条线的两端都落进来时才算得：图片 → 生成算参考图，正文 → 生成算提示词，生成 → 视频是成片的落点，车厢 → 生成是这一段的出片落点（见「车厢」一节）。
- 出图与出片的执行链与「出图」「出片」两页同源同口径（见图像生成节点一节与 `docs/imagegen.md`、`docs/video.md`）：出图是 `/neo_image_gen/generate` + `/status` + `/result`，简单视频是 `/neo_video_gen/simple`，车厢的出片是逐段闭环节 `/neo_video_gen/run_segment`。
视频生成节点就是图像生成节点那一张卡把种类换成视频（`metadata.kind = "video"`）：四枚胶囊换成技能、时长、尺寸，最后一行是「生成视频」与取消任务几枚描边胶囊。

| 控件           | 说明                                                                                                                                                                                                                                                                         |
|                |                                                                                                                                                                                                                                                                              |

| 参考位         | 参考图 / 参考视频 / 参考音频按连线顺序成组进 payload 的 `references.images` / `references.videos` / `references.audios`，首尾帧占「首」「尾」两个槽。

| 首帧与尾帧     | 图生视频（f2v）的胶囊带两个「参考图 · 首」「参考图 · 尾」槽，按连线顺序里第一张、第二张带图的节点落位；第一张的节点标「首」，第二张标「尾」。没带图的节点顶过这两个槽时说一句并挪到参考图组里。
| 参考桶         | 参考视频（r2v）按连进来的片与声音各自成组：卡上写「参考视频 · N」「参考音频 · N」，payload 走 `references.videos` / `references.audios`。
| 参考锁与锚点锁 | 车尾卡上两枚胶囊（串联与整车共用）：参考锁（`metadata.chain_ref_lock`）把列上铺的参考图顶到每一段自己的参考前面，锚点锁（`metadata.chain_anchor_lock`）把整列的锚点盖过配方。
| 自定参数       | 就在技能弹窗右栏：这一发临时换的生视频模型 / Text Encoder / VAE（视频）/ VAE（音频）/ LoRA / 步数（表单与出视频页那块共享同一份），留空 = 跟随该技能 config 与全局生视频设置，步数没改过就跟着技能配置走。存法与出图同一项 `metadata.gen_params`，换技能整项清掉；模型清单没读到（离线）时右栏那几行铺不出东西。                              |
| 配方胶囊       | 这一列跑的是哪一份配方在铺的时候定下、记在每一厢身上（`/rs_recipes/list` 里 `type = "video_director"`、`source` 不是 `preset` 的那些）；车尾只把它写出来，不在这里换（见「添加配方」）。                                                                                       |
| 段与锚点       | 这一段用哪一枚技能读配方里那一份；这一段跑几秒在顶行那一枚数框上改，写进配方那一段（导演页与下一发读的都是这一份）；锚点三挡（两端锚点 / 只钉首帧 / 不用锚点）与步数 / 连续性 / 上下文帧在车尾「参数」那一扇窗里。提示词与参考素材默认也取配方那一份；连过来的文本与图片节点是这一发的画布覆盖。                                                                       |
| 参考素材       | 车厢顶行右端写这一段用的参考素材计数：厢上方连过来的素材排在配方那一段自己的素材前面，一起数在这一行，铺成节点的同一份不重复数。素材本身是厢上方那几张节点 —— 参考图是图片节点、参考视频是视频输入节点、参考音频是音频输入节点，卡上不重复铺预览                                                |
| 技能胶囊       | 车尾那一枚：空着 = 每一段用配方里那一段自己的技能，选一枚 = 整列共用这一份；配方里没有技能又空着时胶囊上写「这份配方没有技能：在车尾选一个视频技能」。点开就是出视频页那一枚技能弹窗，左栏第一项就是「跟随配方 …」，右栏是整列出片共用的那一条模型链与 LoRA（步数在「参数」窗里，不在这一枚上）                                                       |
| 分辨率胶囊     | 车尾那一枚：空着 = 跟这一份配方的共享分辨率（配方 `shared` 的宽 / 高），选一枚 = 整列出片都用这一挡，写进车尾 `metadata.width` / `height` 并随每一发出片交出去                                                                                                 |
| 参数窗          | 车尾「参数」开一扇窗，收着步数 / 锚点 / 连续性 / 上下文帧 / 种子五项，每行一枚胶囊或一个数（下拉是页面里的胶囊菜单，不是系统原生下拉，菜单开在窗自己那一层，不会被遮罩压住）；窗里说明「每一段的时长在车厢上那一枚框里改，写进配方那一段」；点窗外、右上角 × 与 Esc 都收窗                                                                    |
| 种子           | 参数窗里那一个数，留空 = 每段各换随机，填值 = 各段种子是它加段号，改完当场落进车尾的 `metadata.seed`                                                                                                                                                          |
| 顶行那一句     | 整列共用的那一句只在车尾顶行露一份：「链上 {n} 段 · 启用 {m} 段 · {配方名}」；车厢顶行写「段 {n} · 时长数框 · 配方名 · 生效技能 · 参考素材计数」，两行是同一套排版，卡上都不铺第二份概览                                                                           |
| 停用（栏上）   | 节点上方那一排的头一枚：「停用」/「启用」换着写，写进 `metadata.disabled`；停用的那一张压暗、挂「已停用」徽标，出图、出片与整列出片都跳过它（见「车尾与整列出片」）                                          |
| 车厢上铺什么   | 「添加配方」铺出来的那一段（`metadata.recipe` + `metadata.segment`）只带这一段：卡面写段号、这一段时长那一枚数框、这一段用的技能、正文与参考素材的出处和预览，卡上一枚钮都没有（停用 / 复制 / 删除都在节点上方那一排）；锚点 / 连续性 / 上下文帧 / 步数 / 种子与「生成视频」都不在它身上——那一列跑哪些段、怎么跑、出片全在车尾那一张视频生成节点上（见「添加配方」与「车尾与整列出片」） |
| 提示词来源     | 框里铺的是这一段生效的那一句，按 连过来的正文 > 车厢自己写的那一句 > 配方里那一段那一句 取，来源那一枚写着「画布」还是「车厢」。车厢没写过时框里就是配方那一段那一句，改过才写进 `metadata.content`（与提示词节点同一份存法，随撤销、随复制、随落盘）；连过来的正文在跑时这一块锁着——那一发出的是连过来的那一句，改框里这一句跑不到，断线就回到车厢这一句           |
- 种子只在串联车尾那一张卡上：右端那一枚数字输入位，`-1` 是每段各换种子（默认），填 0 与负数都收回 `-1`，填正数就是固定种子、各段种子是它加段号；视频生成节点那一张卡不留种子输入位，简单出片固定交 `-1`，要复现那一发去出视频页填种子。
- 成片按连线写回下游第一张空着的视频节点（`metadata.filename` + `subfolder`，画面走 `/neo_gallery/video`）；没有空着的就在右下新建一张并接上这一发，撤销一次退掉新建的那一张。
- 这一发在跑时节点挂运行态（边框与标签跑光），这一发没收摊不叠第二发。
- 切走画布、离开这一页、删掉这台节点都停掉这一发的轮询：脱手的片只写进那一台节点，不写旧画布。

## 图像编辑节点

画布上的图像编辑走绘画页那一条编辑链（`type = "edit"`，从「加节点」菜单里的「加图像编辑节点」铺）：这一张只管选技能与出图，被改的那一张与要用的提示词都不在节点上，从连进来的线那头取 —— 与图像生成节点同一套接法。这一版只开「常规编辑」——局部重绘的涂抹、点选删除的点击与扩图的拖框都要在原图上画，画布上的卡不做这一发，那一发在「编辑」页。

- 卡上一行控件、一行状态：技能胶囊、张数胶囊与出图钮，最后一行写这一发的进度与失败原因。节点选中时那一排是停用 / 复制 / 删除，没有选图位，也没有提示词位。
- 多张图进同一发：连进来的图片节点按连线顺序进参考，第一张就是被改的那一张（编辑链认第一张）；同一张连两条线只算一份。一条图片都没连，出图只说一句「把要编辑的那一张图片节点连过来」，不发请求。
- 这一发的提示词就是连进来的提示词节点正文，按连线顺序拼；一条都没连，出图只说一句「把要用的提示词节点连过来」，不发请求。
- 技能与自定参数就是绘画页那一枚胶囊（主模型 / LoRA 留空 = 跟随该技能配置与全局生图设置，改动存在 `metadata.gen_params`）。选到不吃参考图的那一张技能时出图只说一句「{skill} 不吃参考图，换一张技能再编辑」，不发请求。目标尺寸不在节点上钉：跟着技能配置与全局生图设置走。
- 载荷带 `skip_enhance`（编辑链不加强化提示词），与绘画页编辑面板那一发同一口径；进度与失败原因写在卡上那一行，跑起来写「编辑中 {done}/{total}」，跑着时出图收成软底并给出「取消任务」。
- 结果走图像生成节点那一条写回：按连线顺序填这台节点下游那几张空图片节点，多出来的在右侧新建图片节点接上这台编辑节点。
- 没有执行队列时出图只说一句「出图需要 ComfyUI 执行队列：点顶栏 ComfyUI 胶囊启动，好了再按一次」，不替用户拉内核；停用的那一张按下去只说自己已停用，与图像生成节点那一发同一套闸门。

## 文本增强节点与图片反推节点

画布上的提示词增强与图片反推走首页那两条 LLM 链（`type = "enhance"` 从「加节点」菜单的「加文本增强节点」铺，`type = "reverse"` 从「加图片反推节点」铺）：这两张卡都不带内容 —— 要重写的正文与要反推的那一张都从连进来的线那头取，成文都写进下游的提示词节点。两条链都在桌面端自服的能力表上（`app/studio_caps.py` 的 `prompt_enhance` / `prompt_reverse`），离线窗口里照跑，要的是本机配好 LLM，不是执行队列。

- 卡上一行控件、一行状态：文本增强节点的胶囊是「用哪一条增强技能」，留空 = 后端按输入智能判断（带图走反推、不带图走默认增强），与首页「提示词增强」页那一枚同一口径，存在 `metadata.skill_id`；反推节点的胶囊是输出语言（中文 / 英文），存在 `metadata.language`。最后一行是「增强」/「反推」那一枚运行钮。
- 正文逐段落在状态行上，写「增强中 · {n} 字」/「反推中 · {n} 字」—— 数的是这一发已经收到的字数，不是步数；每 40 字报一次，逐 token 整层重画会把节点上的打字与拖动全卡住。跑起来运行钮收成软底并给出「取消任务」：取消只断这一发的流，在途的半截正文不落这一张画布。
- 增强吃连进来的提示词节点正文，按连线顺序拼一条送进去；一条都没连，按下去只说一句「把要增强的提示词节点连过来」，不发请求。反推吃连线顺序里第一张启用的图片节点，与出图取参考同一条顺序；那一张没有素材路径时按下去只说一句「反推只吃素材库里的图：连一张带素材路径的图片节点过来」，不发请求（配方素材不在 Output 目录里，后端认不到）。
- 成文按连线顺序填这台节点下游第一张空着的提示词节点（停用的与有字的都不当落点）；下游没有空位就在它右下方新建一张接上。整发一次压栈 —— 撤销一次退掉这一发落下的改动。节点已经不在这一张画布上时（撤销掉了）只说一句「提示词已生成」，一个字节都不写。
- 后端没回正文、链断了都在卡上那一行写失败原因，并说一句「增强失败」/「反推失败」；能力位缺了按下去只说一句「该功能需要 ComfyUI：点顶栏 ComfyUI 胶囊启动，好了再按一次」，不替用户拉内核。停用的那一张按下去只说自己已停用，与图像生成节点那一发同一套闸门。

## 文字故事板节点

画布上的文字故事板走导演页那一条段生成链（`type = "storyboard"`，从「加节点」菜单的「加文字故事板节点」铺）：要拆的那一段话就在这张卡上 —— 一个主题（「一只猫去冒险」）或整篇剧本，运行把每一段的提示词写进连过来的车厢。请求是 `/rs_recipes/director_generate_segments`，与导演页「从一段话生成每一段」同一发；它在桌面端自服的能力表上（`app/studio_caps.py` 的 `storyboard`），离线窗口里照跑，要的是本机配好 LLM，不是执行队列。

- 卡上是正文框（`metadata.content`）、每一段时长那一枚数框（`metadata.segment_seconds`，1–3600 秒，写歪了钳进这一份区间）与「生成段提示词」那一枚运行钮，最后一行是这一发的状态。
- 一行短文本当主题交后端展开；换了行或长过 60 字就当剧本交后端，由后端按行拆段。
- 成文按连线顺序写进连过来的车厢，一厢一段：段数多于车厢时后面的段不进这一发，车厢多于段数时后面那几厢不动，卡上说一句「生成 {n} 段 · 链上 {m} 厢：按连线顺序一厢一段」。连进车厢的正文在出片时照旧优先 —— 这一发写的是车厢自己那一句。
- 段时长写进配方那一段（`/rs_recipes/set_segment_duration`，导演页、重铺一列与出片读的都是这一份），只有车厢记着配方名时才有这一发：手工铺的车厢没有配方，段时长就没有落点。这一发是配方文件的写，不进画布撤销栈，改回去在车厢顶行那一枚数框上改。
- 生成的那几段记在这一张节点自己的 `metadata.segments`（连生成时刻 `metadata.segments_at`），卡上最后一块就是那几行的预览 —— 撤销、复制与落盘都带着走。切画布项目与卸页把在途的那一发脱手，一个字节都不写回旧画布。

## 「添加配方」铺一列

「添加配方」是条上「加节点」菜单里的一行：点开是一份配方列表弹窗（读 `/rs_recipes/list`），卡上写着配方名与那一行概览（段数 · 模式 · 技能 · 宽高 · 总时长）。点一张卡就把这一份配方铺成一列火车，摊完弹窗自己收掉，整批节点与连线压进同一份撤销栈，撤销一次退掉整批，铺完就是普通节点。列表读不到（离线、配方没保存过）就在弹窗里说清楚；段数超过一列上限（24 段）说一句就停，不落半列。

| 铺出来的东西   | 是什么                                                                                                                                                                                                                                                                 |
|---------------| -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 每一厢         | 一段一张车厢节点（`metadata.recipe` + `metadata.segment`），3 厢一行（9 段落 3×3、6 段落两行三列，与出视频页的九宫格 / 六宫格一列一行对得上），行里首尾相接连成链边（`上一厢 → 下一厢`）                                                                               |
| 厢上的参考素材 | 这一段写的参考素材落在自己那厢的正上方，按类别排成一行（图 → 参考视频 → 参考音频）：图片素材落图片节点、参考视频落视频输入节点、参考音频落音频输入节点（每一厢图 5 / 参考视频 3 / 参考音频 3，一行最多 8 张），按连线接进厢，节点带 `metadata.asset` + `metadata.recipe`；栏上「取用素材」/「换素材」换成素材库的一张、取到几张铺几张，换成素材库的一张时配方那一份出处一起收掉。播片与播音走 `/rs_recipes/asset`（配方 assets/ 里那一份，不经 input/），出片那一发三桶一起交后端 |
| 车尾           | 一列一台视频生成节点（`metadata.chain = "train"`、`metadata.kind = "video"`），接在最后一厢右边那一格；整列共用的那一个视频技能与锚点 / 连续性 / 上下文帧 / 步数 / 种子都在这一张卡上                                                                                      |
| 换配方         | 这一列跑哪一份配方在铺的时候定下、记在每一厢身上，车尾只把它写出来；要换配方是条上再按一次「添加配方」重铺一列，不在车尾换                                                                                                                                             |
| 一份改动       | 摊出来的节点与连线压进同一份撤销栈，撤销一次退掉整批；之后就是普通节点——正文能改、胶囊照换、随复制走、随画布落盘                                                                                                                                                       |
| 停用（在栏上） | 节点上方那一排的头一枚写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标；链上没有启用的段时点整列出片说一句就停，不发请求                                                                                                                     |

铺完说一句「已铺好 {n} 段：参考素材按连线接进每一厢，出片与整列共用的技能在车尾」，选中落在铺出来的那几厢，画面把自己拉回这一列上（`fitView`）。

摊出来的段节点出片走的还是同一条链，参考素材按节点类型分 `references.images` / `references.videos` / `references.audios` 三档交出去，同一份素材连两条线也只算一份：

| 连过来的节点                 | 交后端的形状                                                           |
|-----------------------------| -----------------------------------------------------------------------|
| 图片节点（画布上的图）       | `{"kind": "input", "value": "sub/文件.png[output]"}`                   |
| 素材节点（配方里的）         | `{"kind": "recipe", "value": "素材名.png", "recipe": "配方名"}`        |
| 视频输入节点（画布上的片）   | `{"kind": "input", "value": "sub/片.mp4[output]", "media": "video"}`   |
| 音频输入节点（画布上的声音） | `{"kind": "input", "value": "sub/声音.mp3[output]", "media": "audio"}` |

后端把这两类都落到 input 目录再喂加载节点（`studio/image_gen.py` 的 `_reference_name`）：复制成 `input/NeoAgent/名字_时间戳.后缀`。配方不存在、素材文件不在、名字里带路径分隔或 `..`、后缀不属于这一类参考媒体时，这一份素材落空，后端日志说一句，那一发出片照常跑。

## 车尾与整列出片

串联只管排布与顺序：车厢是一张精简卡——段号、这一段时长那一枚数框、这一段用的技能、正文与参考素材的出处和预览，卡上一枚钮都没有（停用、复制与删除都在节点上方那一排）；链边是画布上的排布与停用状态，出片走的还是导演页那一条逐段闭环节，前后端都没有第二套执行链。

- 链序从车尾往回走到车头再翻过来（`段0 → 段1 → … → 段N`），链被剪断就停在走到的那一段，成环认得出来。
- 车尾「生成视频」把启用的那几段依次入队，每一发都是 `/neo_video_gen/run_segment`——ComfyUI 自己的队列按提交顺序跑，成片各落各的下游视频位（接在出片那一段的车厢上），车尾自己不落片。
- 公共参数只有车尾那一份：技能与分辨率两枚胶囊摆在车尾卡上（都空着 = 跟着配方走，选一枚 = 整列共用），锚点 / 连续性 / 上下文帧 / 步数 / 种子收在车尾「参数」那一扇窗里；种子按段号偏移（车尾那一份是起手，`-1` 就是每段各换随机）。车尾技能弹窗右栏盖过的主模型 / Text Encoder / VAE / LoRA 存在车尾的 `metadata.gen_params`，整列每一段那一发都带着同一份。
- 车厢上的「停用」就是节点上方那一排的头一枚，写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标。车厢上没有「生成视频」钮——出片、配方与公共参数都只在车尾那一张上。
- 车厢顶行那一枚时长数框改了那一发就走 `POST /rs_recipes/set_segment_duration`，只写 `segments[].duration_sec` 这一个字段——资产 / 示例 / 结果都不动，区别于整份覆盖的 `/rs_recipes/save`。边界与导演页时长框同一份（1–3600 整数秒），越界先钳到边界再落盘；内置预设配方只读，要先「复制配方」。这一发在跑时框锁着，写成功当场重画这一厢。

- 整列共用的那一句只在车尾顶行露一份：那一行写「链上 {n} 段 · 启用 {m} 段 · {配方名}」，配方名读的是这一列每一厢记着的那一份；车厢上一句都不出。车尾顶行与车厢顶行是同一套排版（同一份 `.ns-canvas-car-head` 行式），两行在画布上看着就是一致的。要换配方是条上「添加配方」重铺一列。
- 车尾「取消任务」取消这一列在跑的每一段；跑起来状态行写「串联出片 {done}/{total}」，失败把后端给的原因留在状态行。
- 断链时说话不乱跑：车尾上游没有车厢说「这台视频生成节点上游没有车厢：用「添加配方」铺一列」，链上全停用说「链上没有启用的段」，都不发请求。
- 车尾的参数走 `metadata` 随画布落盘（`metadata.chain = "train"`、停用 `metadata.disabled = true`）；旧画布上写过的 `metadata.train` 与 `metadata.expand_mode` 读得回来、新版不再写，旧画布没这些键就是不停用、非串联。

## 撤销与落盘

撤销与重做是两条栈，在 `pages/canvas/history.js`：栈里只记节点与连线，视口与背景不进栈；栈深 60，换画布与新建画布清栈。一段拖动、一段打字算一次改动，撤销一次退掉整段。

改动攒在这一页的内存里，900ms 没有新改动落一次盘，视口与背景一起落；离开这一页时先落盘。工具条右边那块就是这一发落没落。`canvas/index.json` 是清单缓存，删掉只从画布文件重建；删除只有 UI 上那一条单条路由，`canvas/` 下没有整目录清的动作。

| 方法 | 路由                  | 说明                                    |
