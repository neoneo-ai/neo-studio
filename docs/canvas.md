# 画布

图片与提示词，铺在一张画布上。画布页把图片节点、提示词节点与生成节点摆在同一张能缩放平移的画面里，节点之间的连线决定出图时带哪些提示词与参考图，也决定出完的图落在哪儿。页面在 `studio/web/studio/pages/canvas/`（`page.js` 是这一页，`geometry.js` / `nodes.js` / `interactions.js` / `store.js` / `history.js` / `gen.js` 在它下面），一份画布的节点与连线落数据根 `canvas/<画布 id>.json`。

## 这一页在哪

- Studio 装配层的 `canvas` 视图：桌面窗口与插件页面同一条路（`studio/web/studio/studio-app.js` 里的 `createCanvasPage`）。素材库与画廊里的「摆到画布」把选中的素材送进这一页，按不重叠的网格铺成图片节点。
- 桌面窗口没有 ComfyUI 运行时也进得来：`/neo_canvas/*` 五条全在 `app/studio_caps.py` 的画布组里，画布读写是纯文件层。出图那一发要执行队列，离线时按出图会去替用户启 ComfyUI 并说一句「出图需要 ComfyUI 执行队列，已试着启动，好了再按一次」，不把按钮锁死。

## 工具条

工具条只一行、不换行：全部是图标钮，名字写在悬停提示与 `aria-label` 里，有快捷键的那几枚把组合键写在悬停提示里；窗口不够宽时整条在条内横向滚（不显示滚动条），不掉到第二行。三组之间一条竖线。

- **画布组**：画布下拉（切换当前画布）与 新建画布 / 重命名 / 删除画布 三枚图标钮。删除画布弹确认，连这一份 `canvas/<画布 id>.json` 一起收掉。
- **节点与剪贴板组**：加图片 / 加提示词 / 加生成节点 三枚带字的钮，随后是 复制选中（Ctrl+D）、剪切选中（Ctrl+X）、复制（Ctrl+C）、粘贴（Ctrl+V）、撤销（Ctrl+Z）、重做（Ctrl+Shift+Z 或 Ctrl+Y）。没有可撤销 / 可重做时那两枚是灰的，灰着时悬停不亮。
- **视图组**：缩小 / 当前比例 / 放大，一条竖线后是 适应内容 与 背景（圆点 / 细线 / 空白三挡），最右是保存状态那一格（未保存 / {秒} 秒后保存 / 已保存 / 保存失败 / 离线）。

## 节点

| 节点    | 这一张是什么                                                                                |
| ---   | ---                                                                                   |
| 提示词节点 | 一整块正文，文字存在 `metadata.content`；一条线指向生成节点时，它的文字按连线顺序拼进这一发的提示词。                          |
| 图片节点  | 一张图，坐标就是素材库的 `filename` + `subfolder`，画面上走 Gallery 缩略图，取不到落占位图。素材卡片从素材库拖进画布也落成图片节点。   |
| 生成节点  | 一张铺满控件的卡（见下节）。它自己不带提示词：提示词与参考图都从连进来的那条线那头取。                                           |
| 主图    | 被记为 `metadata.hero` 的图片节点左上角挂着「主图」徽标；节点选中时从右上角那一排里换。                                  |
| 附加操作栏 | 节点选中时浮在右上角：空着的图片节点多一枚「选图」（开素材库收一张），图片节点有「设为主图」，每类节点都有「复制节点」与「删除节点」。删除把节点和连着它的那些线一起收掉。 |

接线在节点左右两个点上：从右点起手拖到另一张节点上算一条线，落在空白里说一句「连线要落在一个节点上」。四个角上的尺寸柄改这一张的宽高，方向键把选中的节点挪 8px（按住 Shift 挪 40px），每一步都能撤销。

## 生成节点上那一张卡

| 控件    | 说明                                                                                                                                  |
| ---   | ---                                                                                                                                 |
| 技能胶囊  | 图标加技能名的一枚胶囊，宽度按内容自适应；点开从技能页那一份生图技能清单里换一枚，新铺的默认落上一次用的那一枚。卡片上的主模型那一行按这一枚技能的 config 读，读到写模型名，读不到写「主模型：跟随技能配置」。                         |
| 参数那一行 | 比例、长边、张数挤在同一行，各一枚胶囊，控件含义写在悬停提示里。比例与长边默认跟随技能 config 与全局生图设置，胶囊上写「默认比例」「长边尺寸」，盖过的写生效值；比例胶囊的图标就是那个比例的形状。张数点开从 1 到 8 里选一枚（后端一次最多吃 8 张）。 |
| 出图    | 独占最后一行的主按钮：主色实底铺满。这一发在跑时收成软底，位置与宽度都不动。                                                                                              |
| 取消任务  | 这一发在排队或在跑时才出现；按下去交后端出队，节点收回不挂运行态。                                                                                                   |
| 状态那一行 | 「排队中」「生成中 {done}/{total}」跟着后端那一发的进度走；失败时这一行写失败原因，卡片收红。                                                                              |

- 控件的改动当场写进节点的 `metadata`：可撤销、随复制走、随画布落盘。控件那一片起手不拖节点。
- 胶囊的菜单浮在页面那一层（`.ns-canvas-gen-menus`），不在节点里：世界层带 scale、节点裁剪自己的内容，菜单进那一层两头都吃亏。
- 出图请求按连线顺序带上游的提示词与参考图。没有可用的线时说一句「接一条文本或图片线过来再出图」；那一枚技能不吃文本提示词时点名它要参考图。
- 出完的图按连线顺序填下游空着的图片节点，多出来的在右侧新建图片节点并接在这张生成节点上；撤销一次退掉这一发落下的全部图。
- 切走画布或删掉来源节点时这一发脱手：结果不写旧画布，只说一句「图已存进 Output 目录」。
- 技能缺 API Key 时报一句并开技能管理去填；提交失败报「出图失败」，成功报「已出图 {n} 张」。

## 手势与键盘

| 手势 / 按键                       | 做什么                                             |
| ---                           | ---                                             |
| 滚轮                            | 以指针为锚缩放这一片画面                                    |
| 空白处起手拖                        | 平移这一片画面；一格没拖开就是点空白，收笔清掉选中                       |
| Shift + 空白处起手拖                | 框选：拖出的框罩到的节点加进选中，以起点那一刻的选中集为基准                  |
| 中键 / 空格 / Ctrl 按住拖            | 平移这一片画面（空格与 Ctrl 是临时抓手）                         |
| Delete / Backspace            | 删掉选中的节点与连着它们的那些线                                |
| Esc                           | 收掉选中；光标在正文里时先把光标从正文里收出来                         |
| Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y） | 撤销 / 重做                                         |
| Ctrl+D                        | 复制选中的节点                                         |
| Ctrl+C / Ctrl+X / Ctrl+V      | 复制 / 剪切 / 粘贴节点；光标在正文里时那四键是浏览器自己的文字动作，会说一句怎么走回节点 |
| Ctrl+A                        | 全选节点                                            |

工具条上「撤销」「重做」「复制选中」「剪切选中」「复制」「粘贴」的悬停提示里带着这几条快捷键（`aria-label` 保持干净的名字）。

## 撤销与落盘

撤销与重做是两条栈，在 `pages/canvas/history.js`：栈里只记节点与连线，视口与背景不进栈；栈深 60，换画布与新建画布清栈。一段拖动、一段打字算一次改动，撤销一次退掉整段。

改动攒在这一页的内存里，900ms 没有新改动落一次盘，视口与背景一起落；离开这一页时先落盘。工具条右边那块就是这一发落没落。`canvas/index.json` 是清单缓存，删掉只从画布文件重建；删除只有 UI 上那一条单条路由，`canvas/` 下没有整目录清的动作。

## `/neo_canvas/*`

| 方法   | 路由                    | 说明                     |
| ---  | ---                   | ---                    |
| GET  | `/neo_canvas/list`    | 画布清单（索引加索引没记上的画布文件）    |
| GET  | `/neo_canvas/project` | 一张画布的节点与连线（`?id=`）     |
| POST | `/neo_canvas/project` | 落一张画布：写入这一层挡掉写不完的 JSON |
| POST | `/neo_canvas/rename`  | 改标题                    |
| POST | `/neo_canvas/delete`  | 删一张画布                  |

后端在 `studio/canvas.py`，写入走临时文件换回，一把锁管着并发；桌面端离线服务答的是同一组路由，插件运行与离线窗口写的是同一份文件。
