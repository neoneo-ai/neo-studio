# 画布

图片与提示词，铺在一张画布上。画布页把图片节点、提示词节点、生成节点、视频节点与车厢（配方节点）摆在同一张能缩放平移的画面里，节点之间的连线决定出图与出片带哪些提示词与参考图，也决定出完的图与成片落在哪儿。页面在 `studio/web/studio/pages/canvas/`（`page.js` 是这一页，`geometry.js` / `nodes.js` / `interactions.js` / `store.js` / `history.js` / `gen.js` 在它下面），一份画布的节点与连线落数据根 `canvas/<画布 id>.json`。

## 这一页在哪

- Studio 装配层的 `canvas` 视图：桌面窗口与插件页面同一条路（`studio/web/studio/studio-app.js` 里的 `createCanvasPage`）。素材库与画廊里的「摆到画布」把选中的素材送进这一页，按不重叠的网格铺成图片节点，每张按图自己的比例落那一格。
- 桌面窗口没有 ComfyUI 运行时也进得来：`/neo_canvas/*` 五条全在 `app/studio_caps.py` 的画布组里，画布读写是纯文件层。出图与出片那一发要执行队列，离线时按这一发会去替用户启 ComfyUI 并说一句「出图需要 ComfyUI 执行队列，已试着启动，好了再按一次」，不把按钮锁死。

## 工具条

工具条只一行、不换行：全部是图标钮，名字写在悬停提示与 `aria-label` 里，有快捷键的那几枚把组合键写在悬停提示里；窗口不够宽时整条在条内横向滚（不显示滚动条），不掉到第二行。三组之间一条竖线。

- **画布组**：条上只一枚画布名钮（当前画布名 + 箭头），这一组不摆图标钮。点开是一列画布，面板钉在钮下方：点某一行名字就切到那张画布，重命名 与 删除画布 两枚图标钮收在每一行右端——指针落到那一行、键盘 Tab 进那一行才现出来（触屏档没有 hover，两枚常显），改与删都只动那一行的画布；末行是 新建画布。一张画布都没有时列表里就没有改名与删除可按。删除画布弹确认，连这一份 `canvas/<画布 id>.json` 一起收掉。
- **节点组**：一枚「加节点」下拉菜单（点开是 加图片 / 加提示词 / 加生成节点 / 加视频节点 / 添加配方 五行，菜单钉在钮下方），随后是 撤销（Ctrl+Z）与 重做（Ctrl+Shift+Z 或 Ctrl+Y）。剪贴板那四发不上条，走键盘：复制选中 Ctrl+D、剪切选中 Ctrl+X、复制 Ctrl+C、粘贴 Ctrl+V，选中节点与选中连线都认。菜单里每一行是图标加名字（名字同时写在悬停提示与 `aria-label` 里）；点完一项菜单自己收起，按条上那枚钮、按条外任何一处或 Esc 也都收起。没有可撤销 / 可重做时那两枚是灰的，灰着时悬停不亮。
- **视图组**：缩小 / 当前比例 / 放大，一条竖线后是 适应内容 与 背景（圆点 / 细线 / 空白三挡），最右是保存状态那一格（未保存 / {秒} 秒后保存 / 已保存 / 保存失败 / 离线）。

## 节点

| 节点         | 这一张是什么                                                                                                                                                                                                                                                                                                            |
|              |                                                                                                                                                                                                                                                                                                                         |
| 提示词节点   | 一整块正文，文字存在 `metadata.content`；一条线指向生成节点时，它的文字按连线顺序拼进这一发的提示词。进编辑是双击正文，Esc 出编辑，落在节点外那一按也出编辑。                                                                                                                                                           |
| 图片节点     | 一张图，坐标就是素材库的 `filename` + `subfolder`，画面上走 Gallery 缩略图，取不到落占位图。素材卡片从素材库拖进画布也落成图片节点。图片节点按这张图自己的比例落那一格：横图压矮、竖图收窄，长边不超出图片节点默认那一档；拉过的尺寸与串联素材那种小卡不重铺。                                                                                                                             |
| 生成节点     | 一张铺满控件的卡（见下节）。它自己不带提示词：提示词与参考图都从连进来的那条线那头取。                                                                                                                                                                                                                                  |
| 出片节点     | 生成节点那一张卡把种类换成视频（`metadata.kind = "video"`，见下节）：技能、时长、尺寸三枚胶囊，出片走简单视频链。                                                                                                                                                                                                       |
| 车厢         | 导演页那一份配方铺到画布上的那一段（`type = "recipe"`，见「添加配方」）：段号、这一段用的技能与时长、正文与参考素材的出处和预览，卡上一枚钮都没有；整列共用的那一个视频技能与锚点 / 连续性 / 上下文帧 / 步数 / 种子在它那一列的车尾上。                                                                                                                |
| 视频节点     | 一段成片的落点：`metadata.filename` + `subfolder` 有值就播 `/neo_gallery/video`，空着挂「空视频位」占位。                                                                                                                                                                                                               |
| 主图         | 被记为 `metadata.hero` 的图片节点左上角挂着「主图」徽标；节点选中时从节点上方那一排里换。                                                                                                                                                                                                                               |
| 停用         | 整张压暗并挂「已停用」徽标（`metadata.disabled`）：出图、出片与整列出片都跳过它，连过来的正文与参考图也不进那一发，停用的那一张不当成片落点。                                                                                                                                                                           |
| 附加操作栏   | 节点选中时浮在节点上沿外头那一排（栏在节点外，不盖卡上的控件与正文）：头一枚是「停用 / 启用」，空着的图片节点多一枚「选图」（开素材库收一张），图片节点有「设为主图」，每类节点都有「复制节点」与「删除节点」。删除把节点和连着它的那些线一起收掉。栏上的图标分得开：停用是圆圈上一道斜杠、启用是一枚勾、删除是垃圾桶。 |

接线在节点四面上：左与上是入，右与下是出，从出接线点起手拖到另一张节点上算一条线，落在空白里说一句「连线要落在一个节点上」。四枚接线点平时收着不占视线，节点悬停、被选中、正被拉线瞄着时才亮出来（触屏档一直亮着）。两张节点上下叠放时线走竖的那一条：出底边、落顶边 —— 串联展开铺在车厢正上方那块正文与铺在正下方的素材都就近接到车厢那两面，不再绕到右中。四个角上的尺寸柄改这一张的宽高，方向键把选中的节点挪 8px（按住 Shift 挪 40px），每一步都能撤销。

## 生成节点上那一张卡

| 控件    | 说明                                                                                                                                  |
| ---   | ---                                                                                                                                 |
| 技能胶囊  | 图标加技能名的一枚胶囊，宽度按内容自适应；点开从技能页那一份生图技能清单里换一枚，新铺的默认落上一次用的那一枚。卡片上的主模型那一行按这一枚技能的 config 读，读到写模型名，读不到写「主模型：跟随技能配置」。                         |
| 参数那一行 | 比例、长边、张数挤在同一行，各一枚胶囊，控件含义写在悬停提示里。比例与长边默认跟随技能 config 与全局生图设置，胶囊上写「默认比例」「长边尺寸」，盖过的写生效值；比例胶囊的图标就是那个比例的形状。张数点开从 1 到 8 里选一枚（后端一次最多吃 8 张）。 |
| 出图    | 独占最后一行的主按钮：主色实底铺满。这一发在跑时收成软底，位置与宽度都不动。                                                                                              |
| 取消任务  | 这一发在排队或在跑时才出现；按下去交后端出队，节点收回不挂运行态。                                                                                                   |
| 状态那一行 | 「排队中」「生成中 {done}/{total}」跟着后端那一发的进度走；失败时这一行写失败原因，卡片收红。                                                                              |

- 控件的改动当场写进节点的 `metadata`：可撤销、随复制走、随画布落盘。卡上的胶囊、按钮与种子输入，连同浮出栏那几枚，起手不吃这一按（交浏览器在它们上面发 click），按下去就是选中这一张（生成卡与串联车厢整张铺的都是控件，按完不选就看不出按的是哪一张）。卡上其余地方按下拖拖的就是这一张节点——概览行、配方提示词行、参考素材计数、状态与主模型那几行都在其内，正文也不给浏览器选走（`.ns-canvas-node` 整张禁选，只有正文编辑框与种子输入照常可选）。
- 胶囊的菜单浮在页面那一层（`.ns-canvas-gen-menus`），不在节点里：世界层带 scale，菜单进那一层才不跟着缩放、也不会被控件行裁掉。
- 出图请求按连线顺序带上游的提示词与参考图。没有可用的线时说一句「接一条文本或图片线过来再出图」；那一枚技能不吃文本提示词时点名它要参考图。
- 出完的图按连线顺序填下游空着的图片节点，多出来的在右侧新建图片节点并接在这张生成节点上；撤销一次退掉这一发落下的全部图。
- 切走画布或删掉来源节点时这一发脱手：结果不写旧画布，只说一句「图已存进 Output 目录」。
- 技能缺 API Key 时报一句并开技能管理去填；提交失败报「出图失败」，成功报「已出图 {n} 张」。

- 一条线的两端都落进来时才算得：图片 → 生成算参考图，正文 → 生成算提示词，生成 → 视频是成片的落点，车厢 → 生成是这一段的出片落点（见「车厢」一节）。
- 出图与出片的执行链与「出图」「出片」两页同源同口径（见生成节点一节与 `docs/imagegen.md`、`docs/video.md`）：出图是 `/neo_image_gen/generate` + `/status` + `/result`，简单视频是 `/neo_video_gen/simple`，车厢的出片是逐段闭环节 `/neo_video_gen/run_segment`。
出片节点就是生成节点那一张卡把种类换成视频（`metadata.kind = "video"`）：四枚胶囊换成技能、时长、尺寸，最后一行是「生成视频」与取消任务两枚描边胶囊。

| 控件           | 说明                                                                                                                                                                                                                                                                         |
|                |                                                                                                                                                                                                                                                                              |
| 技能胶囊       | 清单就是出视频页那一份视频技能（`/rs_prompts/skills` 里 `gen_video` 的那些）；缺 API Key 时说一句并开技能管理去填。                                                                                                                                                          |
| 时长胶囊       | 2–32 秒，逐秒一挡。                                                                                                                                                                                                                                                         |
| 尺寸胶囊       | 第一挡「跟随尺寸」跟出视频页那台全局默认（`video_defaults` 的宽 / 高），其余按这一枚技能自己的比例铺 9 挡、最长边 1280；盖过的尺寸写回同一份共享默认，技能换了就丢掉按旧技能盖过的那一挡。                                                                                   |
| 生成视频       | 控件行同档的描边胶囊（出图那一枚才是主按钮）：按连线顺序带上游提示词，参考素材取连进来的第一张图；技能 `requires_ref` 要参考图而没连图时在画布上就拦下，不进队列。                                                                                                           |
| 配方胶囊       | 这一列跑的是哪一份配方在铺的时候定下、记在每一厢身上（`/rs_recipes/list` 里 `type = "video_director"`、`source` 不是 `preset` 的那些）；车尾只把它写出来，不在这里换（见「添加配方」）。                                                                                       |
| 段与锚点       | 这一段用哪一枚技能、多长时长都读配方里那一份（导演页编辑）；锚点三挡（两端锚点 / 只钉首帧 / 不用锚点）与步数 / 连续性 / 上下文帧在车尾「参数」那一扇窗里。提示词与参考素材默认也取配方那一份；连过来的文本与图片节点是这一发的画布覆盖。                                                                       |
| 参考素材       | 车厢顶行右端写这一段用的参考素材计数：厢上方连过来的素材排在配方那一段自己的素材前面，一起数在这一行。素材本身是厢上方那几张图片节点，卡上不重复铺缩略图                                                                                                                |
| 技能胶囊       | 车尾那一枚：空着 = 每一段用配方里那一段自己的技能，选一枚 = 整列共用这一份；配方里没有技能又空着时胶囊上写「这份配方没有技能：在车尾选一个视频技能」                                                                                                                        |
| 分辨率胶囊     | 车尾那一枚：空着 = 跟这一份配方的共享分辨率（配方 `shared` 的宽 / 高），选一枚 = 整列出片都用这一挡，写进车尾 `metadata.width` / `height` 并随每一发出片交出去                                                                                                 |
| 参数窗          | 车尾「参数」开一扇窗，收着步数 / 锚点 / 连续性 / 上下文帧 / 种子五项，每行一枚胶囊或一个数（下拉是页面里的胶囊菜单，不是系统原生下拉，菜单开在窗自己那一层，不会被遮罩压住）；窗里说明「每一段的时长跟着配方走」；点窗外、右上角 × 与 Esc 都收窗                                                                    |
| 种子           | 参数窗里那一个数，留空 = 每段各换随机，填值 = 各段种子是它加段号，改完当场落进车尾的 `metadata.seed`                                                                                                                                                          |
| 顶行那一句     | 整列共用的那一句只在车尾顶行露一份：「链上 {n} 段 · 启用 {m} 段 · {配方名}」；车厢顶行写「段 {n} · 配方名 · 时长 · 生效技能 · 参考素材计数」，两行是同一套排版，卡上都不铺第二份概览                                                                           |
| 停用（栏上）   | 节点上方那一排的头一枚：「停用」/「启用」换着写，写进 `metadata.disabled`；停用的那一张压暗、挂「已停用」徽标，出图、出片与整列出片都跳过它（见「车尾与整列出片」）                                          |
| 车厢上铺什么   | 「添加配方」铺出来的那一段（`metadata.recipe` + `metadata.segment`）只带这一段：卡面写段号、这一段用的技能与时长、正文与参考素材的出处和预览，卡上一枚钮都没有（停用 / 复制 / 删除都在节点上方那一排）；锚点 / 连续性 / 上下文帧 / 步数 / 种子与「生成视频」都不在它身上——那一列跑哪些段、怎么跑、出片全在车尾那一张生成节点上（见「添加配方」与「车尾与整列出片」） |
| 提示词来源     | 框里铺的是这一段生效的那一句，按 连过来的正文 > 车厢自己写的那一句 > 配方里那一段那一句 取，来源那一枚写着「画布」还是「车厢」。车厢没写过时框里就是配方那一段那一句，改过才写进 `metadata.content`（与提示词节点同一份存法，随撤销、随复制、随落盘）；连过来的正文在跑时这一块锁着——那一发出的是连过来的那一句，改框里这一句跑不到，断线就回到车厢这一句           |
- 种子只在串联车尾那一张卡上：右端那一枚数字输入位，`-1` 是每段各换种子（默认），填 0 与负数都收回 `-1`，填正数就是固定种子、各段种子是它加段号；出片节点那一张卡不留种子输入位，简单出片固定交 `-1`，要复现那一发去出视频页填种子。
- 成片按连线写回下游第一张空着的视频节点（`metadata.filename` + `subfolder`，画面走 `/neo_gallery/video`）；没有空着的就在右下新建一张并接上这一发，撤销一次退掉新建的那一张。
- 这一发在跑时节点挂运行态（边框与标签跑光），这一发没收摊不叠第二发。
- 切走画布、离开这一页、删掉这台节点都停掉这一发的轮询：脱手的片只写进那一台节点，不写旧画布。

## 「添加配方」铺一列

「添加配方」是条上「加节点」菜单里的一行：点开是一份配方列表弹窗（读 `/rs_recipes/list`），卡上写着配方名与那一行概览（段数 · 模式 · 技能 · 宽高 · 总时长）。点一张卡就把这一份配方铺成一列火车，摊完弹窗自己收掉，整批节点与连线压进同一份撤销栈，撤销一次退掉整批，铺完就是普通节点。列表读不到（离线、配方没保存过）就在弹窗里说清楚；段数超过一列上限（24 段）说一句就停，不落半列。

| 铺出来的东西   | 是什么                                                                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 每一厢         | 一段一张车厢节点（`metadata.recipe` + `metadata.segment`），3 厢一行（9 段落 3×3、6 段落两行三列，与出视频页的九宫格 / 六宫格一列一行对得上），行里首尾相接连成链边（`上一厢 → 下一厢`）                            |
| 厢上的参考素材 | 这一段用的**图片**素材落在自己那厢的正上方，按连线接进厢，节点带 `metadata.asset` + `metadata.recipe`；参考视频与音频不铺成节点，出片那一发由后端从配方那一份取 |
| 车尾           | 一列一台生成节点（`metadata.chain = "train"`、`metadata.kind = "video"`），接在最后一厢右边那一格；整列共用的那一个视频技能与锚点 / 连续性 / 上下文帧 / 步数 / 种子都在这一张卡上 |
| 换配方         | 这一列跑哪一份配方在铺的时候定下、记在每一厢身上，车尾只把它写出来；要换配方是条上再按一次「添加配方」重铺一列，不在车尾换                |
| 一份改动       | 摊出来的节点与连线压进同一份撤销栈，撤销一次退掉整批；之后就是普通节点——正文能改、胶囊照换、随复制走、随画布落盘                          |
| 停用（在栏上） | 节点上方那一排的头一枚写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标；链上没有启用的段时点整列出片说一句就停，不发请求 |

铺完说一句「已铺好 {n} 段：参考素材按连线接进每一厢，出片与整列共用的技能在车尾」，选中落在铺出来的那几厢，画面把自己拉回这一列上（`fitView`）。

摊出来的段节点出片走的还是同一条链，参考素材按节点类型分 `references.images` / `references.videos` / `references.audios` 三档交出去，同一份素材连两条线也只算一份：

| 连过来的节点        | 交后端的形状                                                        |
| ---             | ---                                                               |
| 图片节点（画布上的图） | `{"kind": "input", "value": "sub/文件.png[output]"}`             |
| 素材节点（配方里的）  | `{"kind": "recipe", "value": "素材名.png", "recipe": "配方名"}`   |

后端把这两类都落到 input 目录再喂加载节点（`studio/image_gen.py` 的 `_reference_name`）：复制成 `input/NeoAgent/名字_时间戳.后缀`。配方不存在、素材文件不在、名字里带路径分隔或 `..`、后缀不属于这一类参考媒体时，这一份素材落空，后端日志说一句，那一发出片照常跑。

## 车尾与整列出片

串联只管排布与顺序：车厢是一张精简卡——段号、这一段用的技能与时长、正文与参考素材的出处和预览，卡上一枚钮都没有（停用、复制与删除都在节点上方那一排）；链边是画布上的排布与停用状态，出片走的还是导演页那一条逐段闭环节，前后端都没有第二套执行链。

- 链序从车尾往回走到车头再翻过来（`段0 → 段1 → … → 段N`），链被剪断就停在走到的那一段，成环认得出来。
- 车尾「生成视频」把启用的那几段依次入队，每一发都是 `/neo_video_gen/run_segment`——ComfyUI 自己的队列按提交顺序跑，成片各落各的下游视频位（接在出片那一段的车厢上），车尾自己不落片。
- 公共参数只有车尾那一份：技能与分辨率两枚胶囊摆在车尾卡上（都空着 = 跟着配方走，选一枚 = 整列共用），锚点 / 连续性 / 上下文帧 / 步数 / 种子收在车尾「参数」那一扇窗里；种子按段号偏移（车尾那一份是起手，`-1` 就是每段各换随机）。
- 车厢上的「停用」就是节点上方那一排的头一枚，写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标。车厢上没有「生成视频」钮——出片、配方与公共参数都只在车尾那一张上。
- 整列共用的那一句只在车尾顶行露一份：那一行写「链上 {n} 段 · 启用 {m} 段 · {配方名}」，配方名读的是这一列每一厢记着的那一份；车厢上一句都不出。车尾顶行与车厢顶行是同一套排版（同一份 `.ns-canvas-car-head` 行式），两行在画布上看着就是一致的。要换配方是条上「添加配方」重铺一列。
- 车尾「取消任务」取消这一列在跑的每一段；跑起来状态行写「串联出片 {done}/{total}」，失败把后端给的原因留在状态行。
- 断链时说话不乱跑：车尾上游没有车厢说「这台生成节点上游没有车厢：用「添加配方」铺一列」，链上全停用说「链上没有启用的段」，都不发请求。
- 车尾的参数走 `metadata` 随画布落盘（`metadata.chain = "train"`、停用 `metadata.disabled = true`）；旧画布上写过的 `metadata.train` 与 `metadata.expand_mode` 读得回来、新版不再写，旧画布没这些键就是不停用、非串联。

## 手势与键盘

| 手势 / 按键                     | 做什么                                                                                   |
|                                 |                                                                                          |
| 滚轮                            | 以指针为锚缩放这一片画面                                                                 |
| 空白处起手拖                    | 平移这一片画面（与 ComfyUI 同一手感）；一格没拖开就是点空白，收笔清掉选中                |
| Ctrl + 空白处起手拖             | 框选：拖出的框罩到的节点就是选中集                                                       |
| Shift + 空白处起手拖            | 加选框选：以起点那一刻的选中集为基准，把罩到的节点并进去                                 |
| 中键 / 空格 按住拖              | 平移这一片画面（空格是临时抓手）                                                         |
| 触屏空白那一拖                  | 平移这一片画面：触屏没有 Ctrl 好按，框选只给鼠标与笔                                     |
| 双击提示词节点正文              | 光标落进正文进编辑，Esc 出编辑，点在节点外那一按也出编辑                                 |
| 双击空白                        | 就地铺一张提示词节点，光标落在正文里                                                     |
| Delete / Backspace              | 删掉选中的节点与连着它们的那些线                                                         |
| 拖拽被接走 / 窗口失焦           | 就地收笔：挪出的落点收下，画布上的手势态与框选框收掉，选中不清（这三发都不发 pointerup） |
| Esc                             | 收掉选中；光标在正文里时先把光标从正文里收出来                                           |
| Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y） | 撤销 / 重做                                                                              |
| Ctrl+D                          | 复制选中的节点                                                                           |
| Ctrl+C / Ctrl+X / Ctrl+V        | 复制 / 剪切 / 粘贴节点；光标在正文里时那四键是浏览器自己的文字动作，会说一句怎么走回节点 |

工具条上「撤销」「重做」「复制选中」「剪切选中」「复制」「粘贴」的悬停提示里带着这几条快捷键（`aria-label` 保持干净的名字）。

## 撤销与落盘

撤销与重做是两条栈，在 `pages/canvas/history.js`：栈里只记节点与连线，视口与背景不进栈；栈深 60，换画布与新建画布清栈。一段拖动、一段打字算一次改动，撤销一次退掉整段。

改动攒在这一页的内存里，900ms 没有新改动落一次盘，视口与背景一起落；离开这一页时先落盘。工具条右边那块就是这一发落没落。`canvas/index.json` 是清单缓存，删掉只从画布文件重建；删除只有 UI 上那一条单条路由，`canvas/` 下没有整目录清的动作。

| 方法   | 路由                    | 说明                     |
