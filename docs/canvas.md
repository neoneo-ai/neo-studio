# 画布

图片与提示词，铺在一张画布上。画布页把图片节点、提示词节点、生成节点、视频节点与配方闭环节点摆在同一张能缩放平移的画面里，节点之间的连线决定出图与出片带哪些提示词与参考图，也决定出完的图与成片落在哪儿。页面在 `studio/web/studio/pages/canvas/`（`page.js` 是这一页，`geometry.js` / `nodes.js` / `interactions.js` / `store.js` / `history.js` / `gen.js` 在它下面），一份画布的节点与连线落数据根 `canvas/<画布 id>.json`。

## 这一页在哪

- Studio 装配层的 `canvas` 视图：桌面窗口与插件页面同一条路（`studio/web/studio/studio-app.js` 里的 `createCanvasPage`）。素材库与画廊里的「摆到画布」把选中的素材送进这一页，按不重叠的网格铺成图片节点。
- 桌面窗口没有 ComfyUI 运行时也进得来：`/neo_canvas/*` 五条全在 `app/studio_caps.py` 的画布组里，画布读写是纯文件层。出图与出片那一发要执行队列，离线时按这一发会去替用户启 ComfyUI 并说一句「出图需要 ComfyUI 执行队列，已试着启动，好了再按一次」，不把按钮锁死。

## 工具条

工具条只一行、不换行：全部是图标钮，名字写在悬停提示与 `aria-label` 里，有快捷键的那几枚把组合键写在悬停提示里；窗口不够宽时整条在条内横向滚（不显示滚动条），不掉到第二行。三组之间一条竖线。

- **画布组**：画布下拉（切换当前画布），右端收着 重命名 与 删除画布 两枚图标钮——指针落到这一行、键盘 Tab 进这一行才现出来（触屏档没有 hover，两枚常显），旁边是常显的 新建画布。删除画布弹确认，连这一份 `canvas/<画布 id>.json` 一起收掉。
- **节点组**：一枚「加节点」下拉菜单（点开是 加图片 / 加提示词 / 加生成节点 / 加视频节点 / 加配方节点 五行，菜单钉在钮下方），随后是 撤销（Ctrl+Z）与 重做（Ctrl+Shift+Z 或 Ctrl+Y）。剪贴板那四发不上条，走键盘：复制选中 Ctrl+D、剪切选中 Ctrl+X、复制 Ctrl+C、粘贴 Ctrl+V，选中节点与选中连线都认。菜单里每一行是图标加名字（名字同时写在悬停提示与 `aria-label` 里）；点完一项菜单自己收起，按条上那枚钮、按条外任何一处或 Esc 也都收起。没有可撤销 / 可重做时那两枚是灰的，灰着时悬停不亮。
- **视图组**：缩小 / 当前比例 / 放大，一条竖线后是 适应内容 与 背景（圆点 / 细线 / 空白三挡），最右是保存状态那一格（未保存 / {秒} 秒后保存 / 已保存 / 保存失败 / 离线）。

## 节点

| 节点        | 这一张是什么                                                                                                                                                                                                                                                                                                           |
|             |                                                                                                                                                                                                                                                                                                                        |
| 提示词节点  | 一整块正文，文字存在 `metadata.content`；一条线指向生成节点时，它的文字按连线顺序拼进这一发的提示词。进编辑是双击正文，Esc 出编辑，落在节点外那一按也出编辑。                                                                                                                                                          |
| 图片节点    | 一张图，坐标就是素材库的 `filename` + `subfolder`，画面上走 Gallery 缩略图，取不到落占位图。素材卡片从素材库拖进画布也落成图片节点。                                                                                                                                                                                   |
| 生成节点    | 一张铺满控件的卡（见下节）。它自己不带提示词：提示词与参考图都从连进来的那条线那头取。                                                                                                                                                                                                                                 |
| 出片节点    | 生成节点那一张卡把种类换成视频（`metadata.kind = "video"`，见下节）：技能、时长、尺寸三枚胶囊，出片走简单视频链。                                                                                                                                                                                                      |
| 配方闭环节点| 导演页那一份配方的单段入口（`type = "recipe"`，见下节）：配方 / 步数 / 锚点 / 连续性四枚胶囊、上下文帧与种子、段一行、提示词来源与参考素材两行，只发选中的那一段，卡上还有一枚「展开配方」。                                                                                                                           |
| 视频节点    | 一段成片的落点：`metadata.filename` + `subfolder` 有值就播 `/neo_gallery/video`，空着挂「空视频位」占位。                                                                                                                                                                                                              |
| 主图        | 被记为 `metadata.hero` 的图片节点左上角挂着「主图」徽标；节点选中时从节点上方那一排里换。                                                                                                                                                                                                                              |
| 停用        | 整张压暗并挂「已停用」徽标（`metadata.disabled`）：出图、出片与整列出片都跳过它，连过来的正文与参考图也不进那一发，停用的那一张不当成片落点。                                                                                                                                                                          |
| 附加操作栏  | 节点选中时浮在节点上沿外头那一排（栏在节点外，不盖卡上的控件与正文）：头一枚是「停用 / 启用」，空着的图片节点多一枚「选图」（开素材库收一张），图片节点有「设为主图」，每类节点都有「复制节点」与「删除节点」。删除把节点和连着它的那些线一起收掉。栏上的图标分得开：停用是圆圈上一道斜杠、启用是一枚勾、删除是垃圾桶。|

接线在节点四面上：左与上是入，右与下是出，从出接线点起手拖到另一张节点上算一条线，落在空白里说一句「连线要落在一个节点上」。四枚接线点平时收着不占视线，节点悬停、被选中、正被拉线瞄着时才亮出来（触屏档一直亮着）。两张节点上下叠放时线走竖的那一条：出底边、落顶边 —— 串联展开铺在车厢正上方那块正文与铺在正下方的素材都就近接到车厢那两面，不再绕到右中。四个角上的尺寸柄改这一张的宽高，方向键把选中的节点挪 8px（按住 Shift 挪 40px），每一步都能撤销。

## 生成节点上那一张卡

| 控件    | 说明                                                                                                                                  |
| ---   | ---                                                                                                                                 |
| 技能胶囊  | 图标加技能名的一枚胶囊，宽度按内容自适应；点开从技能页那一份生图技能清单里换一枚，新铺的默认落上一次用的那一枚。卡片上的主模型那一行按这一枚技能的 config 读，读到写模型名，读不到写「主模型：跟随技能配置」。                         |
| 参数那一行 | 比例、长边、张数挤在同一行，各一枚胶囊，控件含义写在悬停提示里。比例与长边默认跟随技能 config 与全局生图设置，胶囊上写「默认比例」「长边尺寸」，盖过的写生效值；比例胶囊的图标就是那个比例的形状。张数点开从 1 到 8 里选一枚（后端一次最多吃 8 张）。 |
| 出图    | 独占最后一行的主按钮：主色实底铺满。这一发在跑时收成软底，位置与宽度都不动。                                                                                              |
| 取消任务  | 这一发在排队或在跑时才出现；按下去交后端出队，节点收回不挂运行态。                                                                                                   |
| 状态那一行 | 「排队中」「生成中 {done}/{total}」跟着后端那一发的进度走；失败时这一行写失败原因，卡片收红。                                                                              |

- 控件的改动当场写进节点的 `metadata`：可撤销、随复制走、随画布落盘。卡上的胶囊、按钮、段钮与种子输入，连同浮出栏那几枚，起手不吃这一按（交浏览器在它们上面发 click），按下去就是选中这一张（生成卡与串联车厢整张铺的都是控件，按完不选就看不出按的是哪一张）。卡上其余地方按下拖拖的就是这一张节点——概览行、配方提示词行、参考素材与缩略图、状态与主模型那几行都在其内，正文也不给浏览器选走（`.ns-canvas-node` 整张禁选，只有正文编辑框与种子输入照常可选）。
- 胶囊的菜单浮在页面那一层（`.ns-canvas-gen-menus`），不在节点里：世界层带 scale，菜单进那一层才不跟着缩放、也不会被控件行裁掉。
- 出图请求按连线顺序带上游的提示词与参考图。没有可用的线时说一句「接一条文本或图片线过来再出图」；那一枚技能不吃文本提示词时点名它要参考图。
- 出完的图按连线顺序填下游空着的图片节点，多出来的在右侧新建图片节点并接在这张生成节点上；撤销一次退掉这一发落下的全部图。
- 切走画布或删掉来源节点时这一发脱手：结果不写旧画布，只说一句「图已存进 Output 目录」。
- 技能缺 API Key 时报一句并开技能管理去填；提交失败报「出图失败」，成功报「已出图 {n} 张」。

## 出片节点与配方闭环节点

出片节点就是生成节点那一张卡把种类换成视频（`metadata.kind = "video"`）：四枚胶囊换成技能、时长、尺寸，最后一行是「生成视频」与取消任务两枚描边胶囊。

| 控件          | 说明                                                                                                                                                                                                                                                                        |
|               |                                                                                                                                                                                                                                                                             |
| 技能胶囊      | 清单就是出视频页那一份视频技能（`/rs_prompts/skills` 里 `gen_video` 的那些）；缺 API Key 时说一句并开技能管理去填。                                                                                                                                                         |
| 时长胶囊      | 2–32 秒，逐秒一挡。                                                                                                                                                                                                                                                        |
| 尺寸胶囊      | 第一挡「跟随尺寸」跟出视频页那台全局默认（`video_defaults` 的宽 / 高），其余按这一枚技能自己的比例铺 9 挡、最长边 1280；盖过的尺寸写回同一份共享默认，技能换了就丢掉按旧技能盖过的那一挡。                                                                                  |
| 生成视频      | 控件行同档的描边胶囊（出图那一枚才是主按钮）：按连线顺序带上游提示词，参考素材取连进来的第一张图；技能 `requires_ref` 要参考图而没连图时在画布上就拦下，不进队列。                                                                                                          |
| 配方胶囊      | 配方闭环节点（`type = "recipe"`）列的是导演页自己存的配方（`/rs_recipes/list` 里 `type = "video_director"`、`source` 不是 `preset`、有段的那些）；换配方时段号回到第 1 段。                                                                                                 |
| 段与锚点      | 锚点胶囊三挡：两端锚点（首 + 尾，最稳）/ 只钉首帧 / 不用锚点。那一段的模式与时长读配方里那一份（导演页编辑），提示词与参考素材默认也取配方那一份；连过来的文本与图片节点是这一发的画布覆盖（见下几行与「展开配方」）。                                                      |
| 步数与连续性  | 步数胶囊：「跟随步数」交 `-1`，跟配方与后端默认，其余「{n} 步」逐挡盖过；连续性胶囊两挡（连续性 开 / 连续性 关）。                                                                                                                                                          |
| 帧窗口与种子  | 上下文帧胶囊写「{n} 帧窗口」，默认那一挡跟着后端；种子是卡右端那一枚数字输入位。                                                                                                                                                                                            |
| 段那一行      | 一枚一段、按段号排开（「段 {n}」），选中那一段抬主色；悬停写「第 {n} 段 · {秒} 秒 · {技能} · 该段提示词」，没写提示词的段落说「这一段没有提示词」。                                                                                                                         |
| 提示词来源    | 一行写明这一发的提示词用的哪一份：连了文本节点写「画布」并抬主色，没连写「配方」并读配方选中那一段的提示词。画布这一份只影响这一发出片，配方里那一份不动。                                                                                                                  |
| 参考素材那一行| 缩略图先列连过来的画布图片节点（走 Gallery 缩略图），再列这一段在配方 `assets/` 里的素材（走 `/rs_recipes/thumbnail?...&dir=assets`，取不到回 `/rs_recipes/asset` 原文件），右边写「{n} 张参考素材」。                                                                      |
| 概览那一行    | 出片节点写「模式链 {技能} · {宽}×{高} · {时长}s」；配方闭环节点写这一发的段数、`宽×高` 与模式链（`i2v → fl2v`），没选配方时写「未选配方」；串联的车尾那台生成节点写「链上 {n} 段 · 启用 {m} 段」。                                                                          |
| 取消任务      | 与出图同一枚：按下去交后端出队，节点收回不挂运行态；串联的车尾那一枚取消这一列在跑的每一段。                                                                                                                                                                                |
| 状态那一行    | 与出图同一行：「生成中 {done}/{total}」读后端快照的 `progress.value` / `progress.max`，失败时写后端给的失败原因，卡片收红；串联的车尾写「串联出片 {done}/{total}」。                                                                                                        |
| 展开方式胶囊  | 配方闭环节点概览那一行右边一枚：「平铺展开」/「串联展开」换着写，写进 `metadata.expand_mode`，卡上的「展开配方」按这一挡铺（见「展开配方」）。                                                                                                                              |
| 停用（栏上）  | 节点上方那一排的头一枚：「停用」/「启用」换着写，写进 `metadata.disabled`；停用的那一张压暗、挂「已停用」徽标，出图、出片与整列出片都跳过它（见「串联展开的车尾与整列出片」）。                                                                                             |
| 车厢上铺什么  | 串联展开铺出来的那一段（`metadata.train = 1`）只带配方名与段号：卡面写这一段的技能与时长、正文与参考素材的出处和预览，卡上一枚钮都没有（停用、复制与删除都在节点上方那一排）；锚点 / 连续性 / 上下文帧 / 步数 / 种子与「生成视频」都不在它身上——那一份在它那一列的车尾上。|

- 出片走的是出视频页那两条后端链：简单出片 `/neo_video_gen/simple`、配方闭环单段 `/neo_video_gen/run_segment`（串联展开的整列出片也是一段一发这条链），状态与取消在同一层 `/{task_id}` 与 `/{task_id}/cancel`，两条链的路由与响应形状在[出视频与导演闭环](h3-video-gen.md)。
- 种子只在配方闭环节点那一张卡上：右端那一枚数字输入位，`-1` 是每次换种子（默认），填 0 与负数都收回 `-1`，填正数就是固定种子；出片节点那一张卡不留种子输入位，简单出片固定交 `-1`，要复现那一发去出视频页填种子。
- 成片按连线写回下游第一张空着的视频节点（`metadata.filename` + `subfolder`，画面走 `/neo_gallery/video`）；没有空着的就在右下新建一张并接上这一发，撤销一次退掉新建的那一张。
- 这一发在跑时节点挂运行态（边框与标签跑光），这一发没收摊不叠第二发。
- 切走画布、离开这一页、删掉这台节点都停掉这一发的轮询：脱手的片只写进那一台节点，不写旧画布。

## 展开配方

配方闭环节点把这一份配方摊到画布上：摊法只有卡上那一枚「展开配方」，认选中的那台卡。展开读的是 `/rs_recipes/list` 里那一份段列表，摊法看卡上「展开方式」那一挡（`metadata.expand_mode`，缺 = 平铺）。

- **平铺展开**（`"grid"`，默认）：一段一行、四列摊开——该段的提示词一台文本节点、该段的参考素材图片节点（最多 4 张，2×2）、一台段节点（配方 / 锚点 / 步数 / 连续性 / 上下文帧 / 种子沿用来源那台卡的值，段号定死为这一段）、段节点右边一台空视频位（出片落的位子）。连线现成：文本与素材接进段节点，段节点接视频位。每一段自己出片。
- **串联展开**（`"train"`）：一段一台车厢沿主线接开，每 4 厢换一行，主线末尾接一台生成节点（`metadata.chain = "train"`）。每一厢摊三样：车厢在它自己那一行，该段的提示词一台文本节点铺在车厢正上方同一列、与车厢同宽（360×220，整段提示词一眼读得完，文字特别多才在框里出滚动条），该段的参考素材图片节点铺在车厢正下方同一列（最多 4 张，2×2，176×124，两列正好铺满车厢那一列的宽）；车厢旁边不铺成片位——成片落点由出片那一发自己找下游空位、没有就新开。一次摊出的张数最多 6 × 段数 + 1 台车尾。链边是 `段0 → 段1 → … → 段N → 车尾`：锚点 / 连续性 / 上下文帧 / 步数 / 种子这一套公共参数只在车尾这一台节点上，车厢只带 `recipe` 与 `segment`。

展开只摊不出片，选中落在摊出来的那批段节点上，摊完画面自己拉回看得见那一片，平铺说一句「已展开 {n} 段：每段一台段节点，提示词与参考素材连过去」，串联说一句「已串开 {n} 段：段节点首尾相接，生成参数在车尾那台生成节点」。

| 展开的规矩    | 说明                                                                                                                                                                     |
|               |                                                                                                                                                                          |
| 段数上限      | 24 段；超了说「段数太多（{n} 段），展开上限 {max} 段」，一台都不摊。                                                                                                     |
| 素材那一列    | 每段最多 4 张，按 `first_frame`、`storyboard`、`refs` 的 `images` / `videos` / `audios` 这个顺序取，排在前面的先摊。                                                     |
| 素材节点存什么| `metadata.asset`（配方 `assets/` 里的文件名）+ `metadata.recipe`，不带 `filename`；画面上走 `/rs_recipes/thumbnail?...&dir=assets`，取不到回 `/rs_recipes/asset` 原文件。|
| 一份改动      | 摊出来的节点与连线压进同一份撤销栈，撤销一次退掉整批；之后就是普通节点——正文能改、胶囊照换、随复制走、随画布落盘。                                                     |
| 说话的那几条  | 卡上没选配方说「先选一份配方」；配方列表读不到说「配方列表读不到：先在导演页保存这份配方」。                                                                             |
| 展开方式      | 卡上那一枚胶囊在「平铺展开」与「串联展开」之间换，写进 `metadata.expand_mode`；卡上的「展开配方」按选中那台卡的这一挡铺                                                  |
| 串联的链边    | 链边只管排布与顺序，不是执行连线：车尾「生成视频」按链序逐段发 `/neo_video_gen/run_segment`，成片各落各的下游视频位，车尾自己不落片                                      |
| 停用（在栏上）| 节点上方那一排的头一枚写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标；链上没有启用的段时点整列出片说一句就停，不发请求                       |
| 断链那一头    | 链被剪断时车尾只跑到走得到的那一段；车尾上游没有车厢时说「这台生成节点上游没有段节点：用串联展开铺一列」，都不按默认值静默跑                                             |

摊出来的段节点出片走的还是同一条链，参考素材按节点类型分 `references.images` / `references.videos` / `references.audios` 三档交出去，同一份素材连两条线也只算一份：

| 连过来的节点        | 交后端的形状                                                        |
| ---             | ---                                                               |
| 图片节点（画布上的图） | `{"kind": "input", "value": "sub/文件.png[output]"}`             |
| 素材节点（配方里的）  | `{"kind": "recipe", "value": "素材名.png", "recipe": "配方名"}`   |

后端把这两类都落到 input 目录再喂加载节点（`studio/image_gen.py` 的 `_reference_name`）：复制成 `input/NeoAgent/名字_时间戳.后缀`。配方不存在、素材文件不在、名字里带路径分隔或 `..`、后缀不属于这一类参考媒体时，这一份素材落空，后端日志说一句，那一发出片照常跑。

## 串联展开的车尾与整列出片

串联只管排布与顺序：车厢是一张精简卡——段号、这一段用的技能与时长、正文与参考素材的出处和预览，卡上一枚钮都没有（停用、复制与删除都在节点上方那一排）；链边是画布上的排布与停用状态，出片走的还是导演页那一条逐段闭环节，前后端都没有第二套执行链。

- 链序从车尾往回走到车头再翻过来（`段0 → 段1 → … → 段N`），链被剪断就停在走到的那一段，成环认得出来。
- 车尾「生成视频」把启用的那几段依次入队，每一发都是 `/neo_video_gen/run_segment`——ComfyUI 自己的队列按提交顺序跑，成片各落各的下游视频位，车尾自己不落片。
- 公共参数（锚点 / 连续性 / 上下文帧 / 步数 / 种子）只有车尾那一份；种子按段号偏移（车尾那一份是起手，`-1` 就是每段各换随机），与平铺展开逐段出片同一口径。
- 车厢上的「停用」就是节点上方那一排的头一枚，写进 `metadata.disabled`：整列出片跳过这一段，这一张压暗并挂「已停用」徽标。车厢上没有「生成视频」钮——出片、配方与公共参数都只在车尾那一张上。
- 车尾「取消任务」取消这一列在跑的每一段；车尾那一行写「链上 {n} 段 · 启用 {m} 段」，跑起来写「串联出片 {done}/{total}」，失败把后端给的原因留在状态行。
- 断链时说话不乱跑：车尾上游没有车厢说「这台生成节点上游没有段节点：用串联展开铺一列」，链上全停用说「链上没有启用的段」，都不发请求。
- 车尾的配方与参数也走 `metadata`，随画布落盘（`metadata.chain = "train"`、车厢 `metadata.train = 1`、`metadata.expand_mode = "train"`、停用 `metadata.disabled = true`）；旧画布没这些键就是平铺、不停用、非串联。

| 触屏空白那一拖                 | 平移这一片画面：触屏没有 Ctrl 好按，框选只给鼠标与笔                                    |

| 拖拽被接走 / 窗口失焦          | 就地收笔：挪出的落点收下，画布上的手势态与框选框收掉，选中不清（这三发都不发 pointerup）|
| Esc                            | 收掉选中；光标在正文里时先把光标从正文里收出来                                          |

## 撤销与落盘

撤销与重做是两条栈，在 `pages/canvas/history.js`：栈里只记节点与连线，视口与背景不进栈；栈深 60，换画布与新建画布清栈。一段拖动、一段打字算一次改动，撤销一次退掉整段。

改动攒在这一页的内存里，900ms 没有新改动落一次盘，视口与背景一起落；离开这一页时先落盘。工具条右边那块就是这一发落没落。`canvas/index.json` 是清单缓存，删掉只从画布文件重建；删除只有 UI 上那一条单条路由，`canvas/` 下没有整目录清的动作。

## `/neo_canvas/*`

| 方法   | 路由                    | 说明                     |
| ---  | ---                   | ---                    |
| GET  | `/neo_canvas/list`    | 画布清单（索引加索引没记上的画布文件）    |

| POST | `/neo_canvas/rename`  | 改标题                    |
| POST | `/neo_canvas/delete`  | 删一张画布                  |

后端在 `studio/canvas.py`，写入走临时文件换回，一把锁管着并发；节点的 `type` 原样落盘（`image` / `text` / `gen` / `video` / `recipe` 与这一版还不认识的新面都不改名，缺了才补 `text`），旧页面认不出的面自己落回正文；桌面端离线服务答的是同一组路由，插件运行与离线窗口写的是同一份文件。
