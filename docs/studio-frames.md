# 视频抽帧

Studio 首页的卡片「视频抽帧」进 `#/frames`（`studio/web/frames/frames.js`）。它和摆姿页、素材库页各自独立：
抽帧在浏览器里做——播放器 seek 到每个时间戳，canvas 画那一帧转 PNG，逐条交本机服务写盘。本机服务只做文件层
的两件事（`studio/frames.py`），桌面端离线服务也答这两条路由。

## 用这条路径

1. **取一条视频**：`从素材库选视频` 开素材库弹窗，点一张卡片换进播放器；`本机视频` 走浏览器自己的选择框，
   选中的文件只在浏览器里，不上盘。非视频（图片、音频）会被挡下并报出文件名。
2. **定起抽点**：进度条按住拖——黄线跟着手走，拖到哪一秒就从那一秒起抽，松手定下来；`跳到首帧` / `跳到末帧`
   会把它挪到片头或片尾，`起点（秒）` 也能直接写数字。
3. **抽帧**：`帧数` 与 `间隔（毫秒）` 决定从起点往后铺开哪几个时间戳；越过片尾的时间戳不会排进来，起点已经在
   片尾之外时页面直接说「起点越过片尾了」，不会抽出一批重复的最后一帧。上限 50 帧一次。
4. **存进素材库**：抽出来的帧只在页面上，按每张卡片的按钮存一条，或按 `全部存进素材库` 连着存。存过的那张卡片
   报「已存」，第二次不再重发。

## 帧落在哪儿

`<ComfyUI 输出目录>/Frames/`，也就是素材库浏览 `output` 时的那个 `Frames` 子目录（素材项的
`subfolder="Frames"`）。帧名带着它的时间戳：`frame-00_07_125.png`（`mm:ss.mmm`，文件名里的冒号换成下划线，
Windows 的文件名不吃冒号）。同名的帧依次追加序号 `_1`：间隔小于 1 秒时同一秒内的两帧不会互相覆盖。

目录由 `studio/gallery.py` 在加载时建好；插件与桌面端用的是同一处落点，帧跟 ComfyUI 自己的输出项在界面上一模一样。

## `/neo_frames/*`

| 方法    | 路由                    | 说明                                                                             |
|---------|-------------------------|----------------------------------------------------------------------------------|
| GET     | `/neo_frames/video`     | 素材库里那条视频的分段响应：素材解析与素材库同一条，seek 才有帧定位，非视频 400  |
| POST    | `/neo_frames/save`      | 一帧 PNG 写进 `Frames`，回 `{filename, subfolder, size}`，一条请求一帧           |

视频必须回分段响应：素材库那条 `/neo_gallery/video` 把整份文件一次读进内存，浏览器没有分段响应时只会顺序往后读，
seek 落回开头——抽出来的帧会全是片头那一帧。抽一批帧时 seek 反复打，这条路由带 `Cache-Control` 让分段复用缓存。

抽帧与存帧期间控件锁住：seek 是一串异步事件，连点会把播放器排在时间戳队列上，看着像「按了抽帧但帧一直不动」。
存帧期间逐条发：一次塞一批的话整批体积会撞上 48MB 请求体上限，而用户要的通常是其中某一张，逐条发不会出现存了一半。

离线与在线同一条路：桌面端窗口没有 ComfyUI 运行时也能抽帧存帧（`app/studio_caps.py` 的抽帧组）。
